1. Brutal truths before you spend a rupee

  1. AWQ is weight-only 4-bit. It shrinks weights about 3.5–4× and memory at inference roughly 3×. It does not make a from-scratch PyTorch implementation fast. Speed comes from fused kernels (vLLM / SGLang AWQ-Marlin). That's why export to the standard AWQ format (Section 13) matters.
  2. Small models get hurt more. A 1B model typically loses 5–10% perplexity at 4-bit. A 70B model typically loses 1–3%. Code, math and long-context tasks degrade more than perplexity suggests, so always test on your task.
  3. The FP16 baseline is often the most expensive part. Quantizing 70B needs one 80 GB GPU (block-by-block). Evaluating 70B in FP16 needs about 170 GB of VRAM (2–3 GPUs). For a 1T model, an FP16 baseline isn't practical. You compare against the published numbers instead, and the guide says so out loud.
  4. "Trillion-parameter" is a logistics problem before it's a GPU problem. Kimi-K2-class means about 1 TB to download, 2–4 TB of disk, many hours of quantization and an 8-GPU node just to serve the result. Budget hundreds of dollars, not $3.
  5. An AI assistant's hardware estimate is a draft, not a decision. LLMs mis-read configs and hallucinate parameter counts. Option A is fast. Option B and 01_inspect_model.py are the truth.
  6. Tuning on the test set is cheating. All tuning in this playbook uses a held-out calibration-style split. WikiText-2 test and lm-eval are run once, at the end.
  7. Spot / community GPUs get reclaimed. The pipeline writes a checkpoint after every block and resumes automatically. Use tmux. Keep your work on a persistent volume.
  8. Idle GPUs burn money. The most common beginner cost isn't compute. It's forgetting to delete a pod or a volume.

2. Audit of the original Week-37 PDF

I read all 40 pages. The math (Sections 1–2 of the original) is right and the 7-day structure is good. These are the issues that would bite you on a real run, and what the new code does about each:

#Problem in the originalConsequence → fix in this project
1Loads the whole FP16 model onto one GPU for collection, search and eval.Caps out around 30B on an 80 GB card, so it can't do 70B, 405B or 1T. Fix: block-by-block streaming. Only one decoder block plus its calibration activations sit on the GPU. Weights are read shard by shard from safetensors.
2Calibration loader uses padding="max_length".Crashes on Llama tokenizers (they have no pad token), and where it doesn't crash it feeds pad tokens into the statistics. Fix: concatenate texts and cut exact seq_len windows, with no padding.
3The AWQ VRAM figure is measured after loading FP16 to the GPU and swapping layers, without resetting peak stats.The reported "AWQ VRAM" is really the FP16 peak, so the "3× drop" claim can't be measured this way. Fix: build the quantized model on the meta device, load packed weights only, reset peak stats, then measure.
4Scales are searched per single Linear, and 1/s is applied at runtime in every layer.Correct, but slow, and it can't be exported to the standard AWQ format (vLLM expects 1/s folded into the previous norm/linear). Fix: Linears that share the same input tensor (q/k/v, gate/up) are detected automatically and get one scale per group. That scale is folded into the producer for known families (Llama, Mistral, Qwen2/3, Gemma*, Mixtral attention). Unknown families keep a runtime inv_s (always correct, native format only).
5No weight-clipping search. Symmetric only. Normalises s by its mean.Leaves accuracy on the table compared with the official AWQ. Fix: add the AWQ clip search, an asymmetric (zero-point) mode (the default, and the standard format) and the official s/√(max·min) normalisation.
6Excludes the output head by the name "lm_head".GPT-NeoX calls it embed_out and others call it output, so they would get quantized by accident. Fix: only quantize Linears inside the repeated decoder blocks. Routers and tiny layers are skipped automatically.
7The "expected" numbers (e.g. AWQ PPL 9.97, 0.74 GB) are illustrative.Putting them in a blog or README as results would be false. Fix: the repo reports only measured JSON, with the hardware, commit hash and timestamp.
8huggingface-cli loginDeprecated in current huggingface_hub. Fix: hf auth login, hf download, hf upload.
9No resume and no checkpointing.A reclaimed spot pod at hour 5 of a 70B run means starting over. Fix: per-block checkpoints and --resume.
10No MoE, FP8, custom-code or own-model support.Fix: Section 0 table, plus the plug-in hook in 3.4.
KEPT The derivation (y = (x/s)·(W·diag(s))ᵀ, s = mean|x|^α, α grid search), the pack/unpack roundtrip test, the forward-verify gate and the day-by-day pass/fail discipline.

4. Step 2: Size the hardware

You need three answers: which GPU, how many, and for how long, and you need them separately for the three phases. They have very different needs:

4.2 Option B: Manual formula (pen and paper)

P      = total parameters (billions)            ← model card / 01_inspect_model.py
P_emb  = vocab x hidden (x2 if lm_head is NOT tied) / 1e9
P_lin  = P - P_emb                               ← the part AWQ quantizes
L, h, I, top_k, I_moe                            ← config.json

FP16 size (GB)          = 2 x P
AWQ size  (GB)          = 0.52 x P_lin + 2 x P_emb      (4 bits + scale/zero per 128 weights ≈ 4.16 bits)
Block (GB)              = 2 x P_lin / L                  (for MoE: count ALL experts in one layer)
Calib act (GB)          = n_samples x seq_len x max(I, top_k x I_moe) x 2 / 1e9

VRAM quantize (GB)      = 2 x Block + 6 x Calib act + 2
VRAM FP16 eval (GB)     = 1.2 x FP16 size
KV cache (GB)           = 2 x L x kv_heads x head_dim x context x batch x 2 / 1e9
VRAM serve AWQ (GB)     = 1.15 x (AWQ size + KV cache)

# GPUs for a phase      = ceil( VRAM_phase / (0.9 x VRAM of one GPU) )
Disk (GB)               = download size + AWQ size + 20
CPU RAM (GB)            ≥ max(16, 3 x Block + 2 x Calib act + 8)     (streaming loader)
# Phase A uses ONE GPU (a block is never split across cards). Phase C (vLLM) uses 1, 2, 4 or 8 GPUs.
Hours (estimate)        ≈ P x 3 min / 60  (A100-class; x1.5 RTX 4090)  + download + 0.5
Cost                    = Σ phases ( #GPUs x $/GPU-hr x hours ) x 1.25   (setup + idle margin)
ESTIMATE The "3 min per billion parameters" speed is my estimate for this pure-PyTorch implementation with clip search on. The first real GPU run calibrates it, and v1.0 of this PDF will carry the measured value.

6.2 Which provider, honestly

  • Paying in INR / GST invoice: E2E Networks or Jarvislabs.
  • 400B–1T: you need a provider with H200/B200 nodes and multi-TB volumes: RunPod (secure), Lambda or Hyperstack. Ask about volume size limits before renting.

9.1 How the algorithm runs (plain words)

  1. Embed the calibration text. 128 windows × 512 tokens go through the embedding layer. The result is the input to block 0.
  2. For each block i (only this block is on the GPU):
    1. Load block i's weights from disk → GPU.
    2. Run the block once with hooks to record the input of every Linear. Linears that receive the same tensor (q/k/v; gate/up; each expert's gate/up) form a group.
    3. For each group: per-channel importance m = mean|x|. Try 20 values of α ∈ [0,1]: s = m^α (normalised), fake-quantize W·diag(s), compute the group output with x/s, measure the error vs FP16. Keep the best s.
    4. Clip search: for each Linear, try shrinking the max-abs value per group (100%→50%) and keep what minimises output error. This tames outlier weights.
    5. Fold 1/s into the previous norm or Linear when it's known. Otherwise store inv_s in the layer. Then pack INT4 + scales (+ zeros).
    6. Run the quantized block on the calibration data and log its error vs. the FP block (block_rel_mse). The input to block i+1 is the FP block's output (official AWQ behaviour, search.propagate: fp), or the quantized output (propagate: quantized, GPTQ-style, a tuning knob). Save a checkpoint, free the GPU, move on.
  3. Write model.safetensors shards + quant_config.json + a copy of the tokenizer and config.

12. Step 10: Hyperparameter tuning

There's no training in AWQ. The "hyperparameters" are the quantization and calibration knobs. Tuning shrinks the gap to FP16 and can never beat FP16. Each trial costs one full quantize + short eval, so tune in stages. Don't brute-force everything at once.

KnobValues triedTypical effectCost
calib.datasetpileval, c4, your domain dataThe biggest win when your use case is narrow (code, legal, Hindi…). Calibrate on what you'll serve.none
quant.group_size128 → 64 → 32Smaller groups are more accurate. 64 usually recovers a good part of the gap.+3% / +9% size
quant.zero_pointtrue / falseAsymmetric is usually better. Symmetric is simpler.tiny
calib.n_samples × seq_len128×512 → 256×512 → 128×2048Small gains. Helps long-context models.more VRAM/time
search.n_grid20 → 40Marginal.2× search time
search.clip, max_shrinkon/off, 0.5 → 0.3Clip on is almost always better.+30% time
quant.skip_moduleskeep the worst k Linears in 16-bit (from search_log.jsonl), often first/last block's down_projTargeted fix for a few sensitive layers.+size per layer
search.propagatefp / quantizedquantized = later blocks see (and compensate for) earlier rounding errors.none
quant.fold_scalesauto / nevernever = also scale groups that cannot fold (e.g. GQA o_proj), so a bit more accurate. But native format only: no vLLM export.tiny runtime cost

12.1 Protocol (strict)

  1. Tuning metric = PPL on a held-out slice (C4 validation windows not used anywhere else). Never WikiText-2 test or lm-eval.
  2. Stage 1: calibration dataset → Stage 2: group size → Stage 3: samples/length → Stage 4: skip-layers. Carry the winner forward each time.
  3. Stop when the gate in 11.2 is met, or after 3 trials in a row that improve less than 0.5%.
  4. Run the final eval (11.1) once on the winner.

18.2 awq/config.py

Job: turn configs/run.yaml into Python objects and refuse bad values before you pay for a GPU.

  • QuantConfig, SearchConfig, CalibConfig, EvalConfig, IOConfig, RunConfig: one dataclass per YAML section. Every field has a default and a comment saying what it does.
  • apply_overrides(): makes --set quant.group_size=64 work. The value is parsed with YAML rules, so 64 becomes an int and false becomes a bool.
  • validate(): fails fast with the fix in the message. Examples: 4-bit only, group size must be one of 32/64/128/256/-1, float32 on CPU, n_samples divisible by batch_size.
  • An unknown key (a typo like groupsize) is an error, not silently ignored.

18.3 awq/quantizer.py

Job: the arithmetic of 4-bit numbers. It doesn't know about AWQ.

  • compute_qparams(w): for every group of 128 weights in a row, compute scale and zero. Asymmetric uses min/max; symmetric uses max|w| with zero fixed at 8.
  • quantize(): q = round(w/scale) + zero, clamped to 0..15. dequantize(): (q − zero)·scale.
  • fake_quant(): quantize, then immediately dequantize. The result is still float but carries the rounding error. The search measures that error.
  • pack_int4() / unpack_int4(): two 4-bit codes per byte (even column in the low nibble, odd column in the high nibble). This is where the 4× storage saving comes from.

18.4 awq/awq_linear.py

  • AwqLinear: stands in for nn.Linear. Buffers: qweight (packed codes), scales, qzeros, optional inv_s, optional bias. forward(x): multiply by inv_s if present → dequantize → ordinary matmul. from_float() builds it from a Linear whose weight is already scaled and clipped.
  • AwqExpertsWeight: stands in for a fused MoE parameter of shape (experts, out, in). The model's own expert loop asks for W[e]; __getitem__ returns expert e's dequantized matrix with 1/s already applied to its columns. The original model code runs unchanged.

18.5 awq/blocks.py

  • find_blocks(model): the decoder blocks are the biggest nn.ModuleList whose children are all the same class. No model names are hard-coded, which is why it works on Llama, Qwen, Mixtral, DeepSeek or your own model.
  • quantizable_linears(block): every nn.Linear in the block, minus routers, tiny layers, layers whose width isn't divisible by the group size, and your skip_modules.
  • fused_experts(block): finds 3-D expert weights named gate_up_proj / down_proj (the transformers ≥ 5 layout).
  • fold_target(block, group): answers "which earlier op can absorb 1/s?" using the table in docs/derivation.md §5. It returns None for unknown families or GQA o_proj; then the scale is kept inside the layer (always correct) or skipped (if you want the vLLM export).
  • allow_clip(): no clipping for q/k projections, same rule as the official code.

18.6 awq/model_io.py

  • resolve_model_path(): an HF id becomes a local folder, downloading only what's needed (configs, tokenizer, weights; *.py only if trust_remote_code).
  • build_skeleton(): builds the model with init_empty_weights(), so every parameter is a zero-byte meta tensor. A 1T-parameter skeleton takes a few seconds and no memory.
  • WeightStore: reads one tensor at a time from safetensors shards. It handles: FP8 + weight_scale_inv (DeepSeek block format) → float; renamed keys (block_sparse_moe ↔ mlp); per-expert checkpoint keys stacked into the fused 3-D layout.
  • ModelSource: load_block(i) fills block i from disk onto the GPU and unload_block(i) turns it back into meta. If a checkpoint can't be mapped key by key, it falls back to a normal full CPU load and logs that loudly (then you need RAM ≥ model size).
  • load_quantized(dir): skeleton → swap in empty AwqLinears → load only packed tensors. Peak memory equals the real quantized footprint, which is why the VRAM numbers in verify/eval are honest.

18.7 awq/calib.py

  • get_calib_tokens(): shuffle documents (seeded), tokenize, join with end-of-text tokens, cut into exactly n_samples × seq_len. No padding: that bug in the original guide is gone.
  • get_eval_tokens(): non-overlapping 2048-token windows of WikiText-2 test, WikiText-2 validation (tuning only) or C4 validation.

18.8 awq/search.py: the AWQ algorithm

  • search_scale(weights, x): candidate 0 is s = 1 (plain RTN). Then for α = 0, 0.05, …, 0.95: s = x_mean^α / w_mean^(1−α), normalised. Error = ‖x·(W − Q(W·s)/s)ᵀ‖², one matmul per candidate, chunked so memory stays bounded. It returns the best s, its α, and the RTN loss for comparison (both are logged per group in search_log.jsonl).
  • search_clip(w, x): for every (output row, group), try shrinking the max to 100%…55% and keep the clip with the lowest partial-output error. Written as a batched einsum, which made it 30× faster than the element-wise version on CPU.
  • apply_clip(): clamps the weights to the chosen limits.

18.9 awq/pipeline.py: the main loop

  • _Catcher: temporarily replaces block 0, stores its inputs and keyword arguments (attention mask, rotary position embeddings), then raises to stop the forward pass. Any architecture gives us exactly what its blocks expect.
  • collect(): runs the FP block once. Forward hooks save each Linear's input. Linears whose input is the same tensor in memory form a group (q/k/v, gate/up). _ExpertRecorder temporarily wraps F.linear to catch which tokens each expert actually received.
  • quantize_block(): (1) search scales for all groups, (2) apply them and fold 1/s, (3) clip, (4) pack into AwqLinear, (5) experts per expert, (6) run the quantized block and log its relative error vs FP. It returns the next block's input (FP outputs by default, like the official code).
  • quantize_model(): the whole run, writing per-block checkpoints and progress.json; resume=True continues from the last finished block. tests/test_pipeline.py proves a crash plus resume gives byte-identical output.

18.10 awq/evaluate.py, awq/export.py, awq/hardware.py, awq/plugin.py

  • evaluate: perplexity() (sum of token NLL over windows), apply_rtn_() (the naive baseline, applied to exactly the weights AWQ touches), generations(), speed(), model_bytes(), run_lm_eval() (passes the in-memory model to lm-evaluation-harness).
  • export: to_gemm() repacks codes into int32 words along output channels in AWQ's order [0,2,4,6,1,3,5,7]; gemm_dequant() is an independent reference decoder used by the tests and by 07_export.py to prove both formats decode to the same weights.
  • hardware: count_params() counts exact parameters on the meta skeleton (tied embeddings once, experts included); estimate() applies the Section 4 formulas; _pick() chooses the cheapest GPU × count per phase (quantize = 1 GPU; serve = 1/2/4/8 for vLLM).
  • plugin: lets a non-transformers model go through the same pipeline via three functions (load, blocks, calib_batches). tests/tiny_plugin.py is a working template.

"""
awq_linear.py — the modules that hold 4-bit weights inside the model.

AwqLinear
    Drop-in replacement for nn.Linear. Stores packed 4-bit codes + per-group scales/zeros.
    forward(x): (optionally x * inv_s) -> dequantize weight -> ordinary matmul.
    `inv_s` (= 1/s) is only present when the AWQ scale could NOT be folded into the
    previous layer; then the layer divides its own input by s at runtime.

AwqExpertsWeight
    Replacement for a fused 3-D Mixture-of-Experts weight (num_experts, out, in), the way
    transformers >= 5 stores experts. The experts' forward code does `W[e]` to get expert e's
    matrix; this module answers `W[e]` with the dequantized matrix, so the original
    (eager) expert code runs unchanged.

Honest note: dequantizing in Python on every forward is the slow-but-correct reference.
Fast inference uses fused int4 kernels (vLLM / SGLang) via scripts/07_export.py.
"""
from __future__ import annotations

import torch
import torch.nn as nn
import torch.nn.functional as F

from .quantizer import compute_qparams, dequantize, pack_int4, quantize, unpack_int4


class AwqLinear(nn.Module):
    def __init__(self, in_features: int, out_features: int, bias: bool, w_bit: int = 4,
                 group_size: int = 128, has_inv_s: bool = False, dtype=torch.float16, device=None):
        super().__init__()
        self.in_features = in_features
        self.out_features = out_features
        self.w_bit = w_bit
        self.group_size = in_features if group_size <= 0 else group_size
        n_groups = in_features // self.group_size
        f = dict(device=device)
        self.register_buffer("qweight", torch.zeros(out_features, in_features // 2, dtype=torch.uint8, **f))
        self.register_buffer("qzeros", torch.zeros(out_features, n_groups, dtype=torch.uint8, **f))
        self.register_buffer("scales", torch.zeros(out_features, n_groups, dtype=dtype, **f))
        if has_inv_s:
            self.register_buffer("inv_s", torch.ones(in_features, dtype=dtype, **f))
        else:
            self.inv_s = None
        if bias:
            self.bias = nn.Parameter(torch.zeros(out_features, dtype=dtype, **f), requires_grad=False)
        else:
            self.register_parameter("bias", None)

    @classmethod
    @torch.no_grad()
    def from_float(cls, linear: nn.Linear, w_bit: int, group_size: int, zero_point: bool,
                   inv_s: torch.Tensor | None = None) -> "AwqLinear":
        """`linear.weight` must ALREADY be W * diag(s) (scaled) and clipped."""
        w = linear.weight.data
        m = cls(linear.in_features, linear.out_features, linear.bias is not None, w_bit, group_size,
                has_inv_s=inv_s is not None, dtype=w.dtype, device=w.device)
        scales, zeros = compute_qparams(w, w_bit, m.group_size, zero_point)
        q = quantize(w, scales, zeros, w_bit, m.group_size)
        m.qweight.copy_(pack_int4(q))
        m.qzeros.copy_(zeros.to(torch.uint8))
        m.scales.copy_(scales.to(w.dtype))
        if inv_s is not None:
            m.inv_s.copy_(inv_s.to(w.dtype))
        if linear.bias is not None:
            m.bias.data.copy_(linear.bias.data)
        return m

    def dequant_weight(self, dtype=None) -> torch.Tensor:
        q = unpack_int4(self.qweight)
        return dequantize(q, self.scales.float(), self.qzeros, self.group_size,
                          dtype=dtype or self.scales.dtype)

    @property
    def weight(self) -> torch.Tensor:
        """Some model code reads `.weight` (e.g. for its dtype). Return the dequantized matrix."""
        return self.dequant_weight()

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        if self.inv_s is not None:
            x = x * self.inv_s.to(x.dtype)            # the "x / s" half of the AWQ identity
        w = self.dequant_weight(dtype=x.dtype)
        return F.linear(x, w, None if self.bias is None else self.bias.to(x.dtype))

    def extra_repr(self) -> str:
        return (f"in={self.in_features}, out={self.out_features}, bits={self.w_bit}, "
                f"group={self.group_size}, inv_s={self.inv_s is not None}, bias={self.bias is not None}")


class AwqExpertsWeight(nn.Module):
    """Quantized stand-in for a fused expert parameter of shape (E, out, in)."""

    def __init__(self, num_experts: int, out_features: int, in_features: int, w_bit: int = 4,
                 group_size: int = 128, dtype=torch.float16, device=None):
        super().__init__()
        self.num_experts, self.out_features, self.in_features = num_experts, out_features, in_features
        self.w_bit = w_bit
        self.group_size = in_features if group_size <= 0 else group_size
        ng = in_features // self.group_size
        f = dict(device=device)
        self.register_buffer("qweight", torch.zeros(num_experts, out_features, in_features // 2,
                                                    dtype=torch.uint8, **f))
        self.register_buffer("qzeros", torch.zeros(num_experts, out_features, ng, dtype=torch.uint8, **f))
        self.register_buffer("scales", torch.zeros(num_experts, out_features, ng, dtype=dtype, **f))
        self.register_buffer("inv_s", torch.ones(num_experts, in_features, dtype=dtype, **f))

    @torch.no_grad()
    def set_expert(self, e: int, w_scaled: torch.Tensor, inv_s: torch.Tensor | None, zero_point: bool):
        scales, zeros = compute_qparams(w_scaled, self.w_bit, self.group_size, zero_point)
        q = quantize(w_scaled, scales, zeros, self.w_bit, self.group_size)
        self.qweight[e].copy_(pack_int4(q))
        self.qzeros[e].copy_(zeros.to(torch.uint8))
        self.scales[e].copy_(scales.to(self.scales.dtype))
        if inv_s is not None:
            self.inv_s[e].copy_(inv_s.to(self.inv_s.dtype))

    def expert_weight(self, e: int, dtype=None) -> torch.Tensor:
        """Dequantized W_e with 1/s folded into its input columns:  Q(W s) diag(1/s)."""
        w = dequantize(unpack_int4(self.qweight[e]), self.scales[e].float(), self.qzeros[e],
                       self.group_size, dtype=torch.float32)
        w = w * self.inv_s[e].float().unsqueeze(0)

"""
blocks.py — find the repeated decoder blocks and the weights inside them, for ANY architecture.

Plain words:
  * Every LLM is "embedding -> N identical blocks -> norm -> output head".
    `find_blocks` finds that list of N blocks by looking for the biggest nn.ModuleList
    whose children are all the same class. No model names are hard-coded.
  * Only weights INSIDE blocks are quantized. The embedding and the output head stay 16-bit
    (that is the AWQ standard, and it is why we never need to know the head's name).
  * `quantizable_linears` lists every nn.Linear in a block, skipping MoE routers, tiny layers,
    and anything you listed in `quant.skip_modules`.
  * `fused_experts` finds transformers>=5 style MoE weights: one 3-D tensor (experts, out, in).
  * `fold_target` answers: "after scaling this group's weights by s, which earlier layer can
    absorb the 1/s for free?"  (RMSNorm/LayerNorm before attention or MLP, or up_proj before
    down_proj.) If none, the scale is stored inside the quantized layer instead.
"""
from __future__ import annotations

import re

import torch.nn as nn

ROUTER_NAMES = {"gate", "router", "shared_expert_gate", "gate_proj_router"}
# Linears whose outputs feed attention scores: the official AWQ skips weight clipping for them.
NO_CLIP_PATTERNS = ("q_", "k_", "query", "key", "Wqkv", "qkv", "q_a_proj", "q_b_proj", "kv_a_proj", "kv_b_proj")
FOLD_FAMILIES = {"llama", "mistral", "qwen2", "qwen3", "gemma", "gemma2", "gemma3_text", "granite",
                 "mixtral", "qwen2_moe", "qwen3_moe", "olmo", "smollm3", "ministral"}


def _numel(module: nn.Module) -> int:
    return sum(p.numel() for p in module.parameters())


def find_blocks(model: nn.Module) -> tuple[str, nn.ModuleList]:
    """Return (dotted_name, ModuleList) of the repeated decoder blocks."""
    best, best_n = None, -1
    for name, mod in model.named_modules():
        if isinstance(mod, nn.ModuleList) and len(mod) >= 1:
            classes = {type(c).__name__ for c in mod}
            if len(classes) != 1:
                continue
            n = _numel(mod)
            if n > best_n:
                best, best_n = (name, mod), n
    if best is None:
        raise RuntimeError("Could not find a list of repeated decoder blocks in this model.")
    return best


def model_type(model_or_config) -> str:
    cfg = getattr(model_or_config, "config", model_or_config)
    text = cfg.get_text_config() if hasattr(cfg, "get_text_config") else cfg
    return str(getattr(text, "model_type", getattr(cfg, "model_type", "")))


def quantizable_linears(block: nn.Module, group_size: int, skip_patterns=()) -> tuple[dict, dict]:
    """Return ({name: nn.Linear} to quantize, {name: reason} skipped)."""
    keep, skipped = {}, {}
    for name, m in block.named_modules():
        if not isinstance(m, nn.Linear):
            continue
        leaf = name.split(".")[-1]
        g = m.in_features if group_size <= 0 else group_size
        if any(p in name for p in skip_patterns):
            skipped[name] = "listed in quant.skip_modules"
        elif leaf in ROUTER_NAMES or m.out_features < 32:
            skipped[name] = "MoE router / tiny layer (kept 16-bit on purpose)"
        elif m.in_features % g != 0 or m.in_features % 2 != 0:
            skipped[name] = f"in_features={m.in_features} not divisible by group_size={g}"
        else:
            keep[name] = m
    return keep, skipped


def fused_experts(block: nn.Module) -> list[tuple[str, str, nn.Module]]:
    """[(module_name, param_name, module)] for 3-D expert weights used as W[e] in eager forward."""
    out = []
    for name, m in block.named_modules():
        if getattr(m, "is_transposed", False):
            continue          # (E, in, out) layout: not supported, stays 16-bit
        for pname, p in m.named_parameters(recurse=False):
            if p.ndim == 3 and pname in ("gate_up_proj", "down_proj", "up_proj"):
                out.append((name, pname, m))
    return out


def allow_clip(name: str) -> bool:
    leaf = name.split(".")[-1]
    return not any(leaf.startswith(p) or p == leaf for p in NO_CLIP_PATTERNS)


def _get(block: nn.Module, dotted: str):
    m = block
    for p in dotted.split("."):
        if not hasattr(m, p):
            return None
        m = getattr(m, p)
    return m


def fold_target(block: nn.Module, group: list[str], family: str):
    """Where can 1/s be absorbed for this group of linears (names relative to block)?

    Returns (kind, module_name) with kind in {"norm", "norm_offset", "linear_out"} or None.
    Only for families whose block structure we know (FOLD_FAMILIES); everything else keeps 1/s
    inside the quantized layer, which is always correct.
    """
    if family not in FOLD_FAMILIES:
        return None
    leaves = {g.split(".")[-1] for g in group}
    parent = group[0].rsplit(".", 1)[0] if "." in group[0] else ""

    def norm(name):
        m = _get(block, name)
        if m is None or not hasattr(m, "weight") or m.weight is None:
            return None
        offset = "Gemma" in type(m).__name__ or family.startswith("gemma")
        return ("norm_offset" if offset else "norm", name)

    if leaves == {"q_proj", "k_proj", "v_proj"}:
        return norm("input_layernorm")
    if leaves == {"gate_proj", "up_proj"} and re.fullmatch(r"(mlp|feed_forward)", parent or ""):
        # Gemma2/3 put a norm AFTER attention ("post_attention_layernorm") and a separate
        # "pre_feedforward_layernorm" before the MLP — the MLP input comes from the latter.
        return norm("pre_feedforward_layernorm") or norm("post_attention_layernorm")
    if leaves == {"down_proj"}:
        up = _get(block, f"{parent}.up_proj") if parent else None
        gate = _get(block, f"{parent}.gate_proj") if parent else None
        if isinstance(up, nn.Linear) and isinstance(gate, nn.Linear):
            return ("linear_out", f"{parent}.up_proj")
        return None
    if leaves == {"o_proj"}:
        v = _get(block, f"{parent}.v_proj")
        o = _get(block, group[0])
        if isinstance(v, nn.Linear) and v.out_features == o.in_features:
            return ("linear_out", f"{parent}.v_proj")
        return None
    return None

"""
calib.py — text in, exact-length token windows out.

Plain words:
  AWQ needs to *watch* the model work on real text to learn which input channels matter.
  We take documents, tokenize them, glue them together with an end-of-text token, and cut
  the stream into `n_samples` windows of exactly `seq_len` tokens.

  NO padding is used. (The original Week-37 guide used padding="max_length", which crashes on
  Llama tokenizers — they have no pad token — and pollutes the statistics with pad tokens.)

Datasets:
  calibration : pileval (official AWQ), c4, wikitext2, or your own .jsonl with {"text": ...}
  evaluation  : wikitext2 (test), wikitext2_val (validation, used only for tuning), c4 (validation)
"""
from __future__ import annotations

import json
import random
from pathlib import Path

import torch


def _iter_texts(name: str, split_hint: str = "train"):
    from datasets import load_dataset

    if name == "pileval":
        ds = load_dataset("mit-han-lab/pile-val-backup", split="validation", streaming=True)
        for ex in ds:
            yield ex["text"]
    elif name == "c4":
        f = "en/c4-train.00000-of-01024.json.gz" if split_hint == "train" else "en/c4-validation.00000-of-00008.json.gz"
        ds = load_dataset("allenai/c4", data_files={"x": f}, split="x", streaming=True)
        for ex in ds:
            yield ex["text"]
    elif name in ("wikitext2", "wikitext2_val", "wikitext2_train"):
        split = {"wikitext2": "test", "wikitext2_val": "validation", "wikitext2_train": "train"}[name]
        if name == "wikitext2" and split_hint == "train":
            split = "train"
        ds = load_dataset("Salesforce/wikitext", "wikitext-2-raw-v1", split=split)
        for ex in ds:
            yield ex["text"]
    elif Path(name).exists():
        with open(name) as fh:
            for line in fh:
                line = line.strip()
                if line:
                    yield json.loads(line)["text"]
    else:
        raise ValueError(f"Unknown dataset {name!r}. Use pileval | c4 | wikitext2 | path/to/file.jsonl")


def get_calib_tokens(tokenizer, dataset: str, n_samples: int, seq_len: int, seed: int = 42) -> torch.Tensor:
    """Return LongTensor (n_samples, seq_len) of calibration tokens."""
    rng = random.Random(seed)
    need = n_samples * seq_len
    eos = tokenizer.eos_token_id if tokenizer.eos_token_id is not None else 0
    # Take a pool of documents, shuffle it with the seed, then fill the token budget.
    pool = []
    for i, text in enumerate(_iter_texts(dataset, "train")):
        if text and len(text.strip()) > 20:
            pool.append(text)
        if len(pool) >= max(4 * n_samples, 512) and sum(len(t) for t in pool) > need * 6:
            break
    rng.shuffle(pool)
    ids: list[int] = []
    for text in pool:
        ids.extend(tokenizer(text, add_special_tokens=False)["input_ids"])
        ids.append(eos)
        if len(ids) >= need:
            break
    if len(ids) < need:
        raise RuntimeError(f"Calibration data too small: got {len(ids)} tokens, need {need}.")
    return torch.tensor(ids[:need], dtype=torch.long).view(n_samples, seq_len)


def get_eval_tokens(tokenizer, dataset: str, seq_len: int, max_windows: int = 0) -> torch.Tensor:
    """Return LongTensor (n_windows, seq_len) of non-overlapping evaluation windows."""
    if dataset in ("wikitext2", "wikitext2_val"):
        texts = list(_iter_texts(dataset, "eval"))
        text = "\n\n".join(texts)
    elif dataset == "c4":
        texts = []
        for i, t in enumerate(_iter_texts("c4", "validation")):
            texts.append(t)
            if i >= 1100:            # same budget as the GPTQ/AWQ papers' c4 eval slice
                break
        text = "\n\n".join(texts)
    elif Path(dataset).exists():
        text = "\n\n".join(_iter_texts(dataset))
    else:
        raise ValueError(f"Unknown eval dataset {dataset!r}")
    ids = tokenizer(text, return_tensors="pt", add_special_tokens=False).input_ids[0]
    n = ids.numel() // seq_len
    if dataset == "c4":
        n = min(n, 256)
    if max_windows and max_windows > 0:
        n = min(n, max_windows)
    if n == 0:
        raise RuntimeError(f"{dataset}: fewer than seq_len={seq_len} tokens")
    return ids[: n * seq_len].view(n, seq_len)

def _build(cls, data: dict | None):
    """Turn a plain dict into the dataclass `cls`, recursing into nested dataclasses."""
    data = dict(data or {})
    known = {f.name: f for f in fields(cls)}
    unknown = set(data) - set(known)
    if unknown:
        raise ValueError(f"Unknown config key(s) in [{cls.__name__}]: {sorted(unknown)}")
    kwargs = {}
    for name, f in known.items():
        if name not in data:
            continue
        default = f.default_factory() if f.default_factory is not MISSING else f.default
        if is_dataclass(default):
            kwargs[name] = _build(type(default), data[name])
        else:
            kwargs[name] = data[name]
    return cls(**kwargs)


def _parse_value(text: str) -> Any:
    """'64' -> 64, 'true' -> True, '[a,b]' -> ['a','b'] (YAML rules)."""
    return yaml.safe_load(text)


def apply_overrides(cfg_dict: dict, overrides: dict[str, Any] | list[str] | None) -> dict:
    """Apply {'quant.group_size': 64} or ['quant.group_size=64'] onto a nested dict."""
    out = copy.deepcopy(cfg_dict)
    if not overrides:
        return out
    if isinstance(overrides, list):
        pairs = {}
        for item in overrides:
            if "=" not in item:
                raise ValueError(f"--set expects key=value, got {item!r}")
            k, v = item.split("=", 1)
            pairs[k.strip()] = _parse_value(v)
        overrides = pairs
    for dotted, value in overrides.items():
        node = out
        parts = dotted.split(".")
        for p in parts[:-1]:
            node = node.setdefault(p, {})
        node[parts[-1]] = value
    return out


def validate(cfg: RunConfig) -> RunConfig:
    """Fail fast, with a message that says what to change."""
    if not cfg.model:
        raise ValueError("config: `model:` is empty. Put a Hugging Face id or a local folder path.")
    if cfg.quant.w_bit != 4:
        raise ValueError("config: quant.w_bit must be 4 (this implementation packs 4-bit only).")
    if cfg.quant.group_size not in (-1, 32, 64, 128, 256):
        raise ValueError("config: quant.group_size must be one of -1 (per-channel), 32, 64, 128, 256.")
    if cfg.quant.fold_scales not in ("auto", "never"):
        raise ValueError("config: quant.fold_scales must be 'auto' or 'never'.")
    if cfg.search.propagate not in ("fp", "quantized"):
        raise ValueError("config: search.propagate must be 'fp' or 'quantized'.")
    if cfg.dtype not in ("float32", "float16", "bfloat16"):
        raise ValueError("config: dtype must be float32, float16 or bfloat16.")
    if cfg.device not in ("cuda", "cpu"):
        raise ValueError("config: device must be cuda or cpu.")
    if cfg.device == "cpu" and cfg.dtype != "float32":
        raise ValueError("config: on CPU use dtype: float32 (half-precision matmuls on CPU are slow/unsupported).")
    if cfg.calib.n_samples % cfg.calib.batch_size != 0:
        raise ValueError("config: calib.n_samples must be divisible by calib.batch_size.")
    if not 0 < cfg.search.max_shrink < 1:
        raise ValueError("config: search.max_shrink must be in (0, 1).")
    return cfg

@torch.no_grad()
def apply_rtn_(model, w_bit: int, group_size: int, zero_point: bool, skip_patterns=()) -> int:
    """In-place naive RTN on exactly the weights AWQ would quantize. Returns #tensors changed."""
    _, blocks = find_blocks(model)
    n = 0
    for block in blocks:
        lin, _ = quantizable_linears(block, group_size, skip_patterns)
        for m in lin.values():
            m.weight.data = fake_quant(m.weight.data, w_bit, group_size, zero_point)
            n += 1
        for _, pname, mod in fused_experts(block):
            p = getattr(mod, pname)
            for e in range(p.shape[0]):
                p.data[e] = fake_quant(p.data[e], w_bit, group_size, zero_point)
            n += 1
    return n


@torch.no_grad()
def perplexity(model, tokens: torch.Tensor, log=None, desc="ppl") -> float:
    dev = input_device(model)
    nll, count = 0.0, 0
    for i in range(tokens.shape[0]):
        ids = tokens[i:i + 1].to(dev)
        logits = model(input_ids=ids, use_cache=False).logits[:, :-1].float()
        target = ids[:, 1:].to(logits.device)
        nll += F.cross_entropy(logits.reshape(-1, logits.shape[-1]), target.reshape(-1), reduction="sum").item()
        count += target.numel()
        if log and (i + 1) % max(1, tokens.shape[0] // 5) == 0:
            log(f"  [{desc}] {i + 1}/{tokens.shape[0]} windows  running ppl={math.exp(nll / count):.4f}")
    return math.exp(nll / count)


@torch.no_grad()
def generations(model, tok, prompts=None, max_new_tokens: int = 48) -> list[str]:
    prompts = prompts or DEFAULT_PROMPTS
    dev = input_device(model)
    outs = []
    for p in prompts:
        ids = tok(p, return_tensors="pt").input_ids.to(dev)
        g = model.generate(ids, max_new_tokens=max_new_tokens, do_sample=False,
                           pad_token_id=tok.pad_token_id if tok.pad_token_id is not None else tok.eos_token_id)
        outs.append(tok.decode(g[0, ids.shape[1]:], skip_special_tokens=True))
    return outs

"""
export.py — turn our native output into the STANDARD AWQ "GEMM" format that vLLM / SGLang load.

Plain words:
  Our native format stores codes as (out, in/2) uint8. The ecosystem format (AutoAWQ "GEMM",
  understood by vLLM's awq / awq_marlin kernels) stores, per Linear:
      qweight : int32 (in, out/8)   eight 4-bit codes per int32, packed along OUTPUT channels,
                                    in the interleaved order [0, 2, 4, 6, 1, 3, 5, 7]
      qzeros  : int32 (in/g, out/8) zero points, packed the same way
      scales  : fp16  (in/g, out)
  plus `quantization_config` in config.json. Dequant rule:  W[o, i] = (q[i, o] - z[i/g, o]) * s[i/g, o].

  This only works when every AWQ scale was folded into the previous layer (no `inv_s` left),
  because vLLM has no slot for a per-input-channel 1/s. Use `quant.fold_scales: auto` on a
  supported family. Fused MoE experts are not exported (stay native).
"""
from __future__ import annotations

import json
import shutil
from pathlib import Path

import torch

from .quantizer import unpack_int4

AWQ_ORDER = [0, 2, 4, 6, 1, 3, 5, 7]
AWQ_REVERSE_ORDER = [0, 4, 1, 5, 2, 6, 3, 7]


def _to_int32(x64: torch.Tensor) -> torch.Tensor:
    x64 = x64 & 0xFFFFFFFF
    return torch.where(x64 >= 2 ** 31, x64 - 2 ** 32, x64).to(torch.int32)


def gemm_pack_codes(codes_in_out: torch.Tensor) -> torch.Tensor:
    """(rows, out) integer codes 0..15 -> (rows, out/8) int32 in AWQ interleaved order."""
    rows, out_f = codes_in_out.shape
    if out_f % 8:
        raise ValueError(f"out_features={out_f} must be divisible by 8 for the AWQ GEMM format")
    c = codes_in_out.to(torch.int64).view(rows, out_f // 8, 8)[..., AWQ_ORDER]
    shifts = torch.arange(0, 32, 4, dtype=torch.int64)
    return _to_int32((c << shifts).sum(-1))


def gemm_unpack_codes(packed: torch.Tensor) -> torch.Tensor:
    """Inverse of gemm_pack_codes: (rows, out/8) int32 -> (rows, out) int64 codes."""
    rows, cols = packed.shape
    p = packed.to(torch.int64) & 0xFFFFFFFF
    shifts = torch.arange(0, 32, 4, dtype=torch.int64)
    nib = (p.unsqueeze(-1) >> shifts) & 0xF                      # (rows, cols, 8) in packed order
    return nib[..., AWQ_REVERSE_ORDER].reshape(rows, cols * 8)


def to_gemm(qweight_native: torch.Tensor, qzeros_native: torch.Tensor, scales_native: torch.Tensor):
    """Native (out, in/2) uint8 / (out, ng) / (out, ng) -> GEMM qweight, qzeros, scales."""
    codes = unpack_int4(qweight_native)                          # (out, in)
    qweight = gemm_pack_codes(codes.t().contiguous())            # (in, out/8)
    qzeros = gemm_pack_codes(qzeros_native.t().contiguous())     # (ng, out/8)
    scales = scales_native.t().contiguous().to(torch.float16)    # (ng, out)
    return qweight, qzeros, scales


def gemm_dequant(qweight: torch.Tensor, qzeros: torch.Tensor, scales: torch.Tensor, group_size: int):
    """Reference dequantization of the GEMM format -> (out, in) float32. Used by tests."""
    codes = gemm_unpack_codes(qweight).float()                   # (in, out)
    zeros = gemm_unpack_codes(qzeros).float()                    # (ng, out)
    in_f = codes.shape[0]
    g = in_f if group_size <= 0 else group_size
    idx = torch.arange(in_f) // g
    w = (codes - zeros[idx]) * scales.float()[idx]
    return w.t().contiguous()


def export_autoawq(qdir: str | Path, out_dir: str | Path, shard_gb: float = 4.0, log=print) -> Path:
    from safetensors import safe_open
    from safetensors.torch import save_file

    qdir, out_dir = Path(qdir), Path(out_dir)
    qc = json.loads((qdir / "quant_config.json").read_text())
    if qc.get("n_linears_with_inv_s", 0):
        raise RuntimeError(
            f"{qc['n_linears_with_inv_s']} layers keep a runtime 1/s (scale could not be folded). The standard "
            "AWQ format has no place for it. Re-quantize with quant.fold_scales=auto on a supported family "
            "(llama, mistral, qwen2/3, gemma*, ...) or ship the native format.")
    if qc.get("n_expert_tensors_quantized", 0):
        raise RuntimeError("Fused MoE experts were quantized natively; the GEMM export does not cover them. "
                           "Ship the native format, or re-run with quant.quantize_experts=false.")
    if qc.get("group_size", 128) <= 0:
        raise RuntimeError("Per-channel (group_size=-1) is not supported by the GEMM export.")
    out_dir.mkdir(parents=True, exist_ok=True)
    quant_names = set(qc["linears"])
    tensors, shards, cur_bytes = {}, [], 0
    limit = int(shard_gb * 1e9)

    def flush():
        nonlocal tensors, cur_bytes
        if tensors:
            shards.append(dict(tensors))
            tensors, cur_bytes = {}, 0

    for f in sorted(qdir.glob("*.safetensors")):
        with safe_open(str(f), framework="pt") as h:
            keys = list(h.keys())
            done = set()
            for k in keys:
                base, _, leaf = k.rpartition(".")
                if base in quant_names:
                    if base in done:
                        continue
                    qw, qz, sc = to_gemm(h.get_tensor(base + ".qweight"), h.get_tensor(base + ".qzeros"),
                                         h.get_tensor(base + ".scales"))
                    new = {base + ".qweight": qw, base + ".qzeros": qz, base + ".scales": sc}
                    if base + ".bias" in keys:
                        new[base + ".bias"] = h.get_tensor(base + ".bias").to(torch.float16)
                    done.add(base)
                else:
                    t = h.get_tensor(k)
                    new = {k: t.to(torch.float16) if t.is_floating_point() else t}
                for nk, nv in new.items():
                    tensors[nk] = nv.contiguous()
                    cur_bytes += nv.numel() * nv.element_size()
                if cur_bytes > limit:
                    flush()
    flush()
    weight_map = {}
    for i, sd in enumerate(shards):
        name = "model.safetensors" if len(shards) == 1 else f"model-{i + 1:05d}-of-{len(shards):05d}.safetensors"
        save_file(sd, str(out_dir / name), metadata={"format": "pt"})
        weight_map.update({k: name for k in sd})
    if len(shards) > 1:
        index = {"metadata": {}, "weight_map": weight_map}
        (out_dir / "model.safetensors.index.json").write_text(json.dumps(index, indent=2))

    for f in qdir.iterdir():
        if f.is_file() and not f.name.endswith(".safetensors") and f.name not in ("quant_config.json", "config.json"):
            shutil.copy2(f, out_dir / f.name)
    cfg = json.loads((qdir / "config.json").read_text())
    skipped = sorted({k.rsplit(".", 1)[-1] for k in qc.get("skipped", {})})
    cfg["quantization_config"] = {
        "quant_method": "awq", "bits": qc["w_bit"], "group_size": qc["group_size"],
        "zero_point": qc["zero_point"], "version": "gemm",
        "modules_to_not_convert": skipped or None,
    }
    cfg["torch_dtype"] = "float16"
    cfg["dtype"] = "float16"
    (out_dir / "config.json").write_text(json.dumps(cfg, indent=2))
    log(f"[export] AutoAWQ-GEMM format -> {out_dir}  ({len(quant_names)} quantized linears, {len(shards)} shard(s))")
    return out_dir

"""
hardware.py — "which GPU, how many, how long, how much?" (Option B of the playbook, as code).

Plain words:
  1. Read the model's config.json (a few KB — no weights are downloaded).
  2. Build the model on the "meta" device to count EXACTLY how many parameters sit in
     quantizable Linear layers, in MoE experts, and outside the blocks (embeddings/head).
     If the skeleton cannot be built, fall back to formulas from config fields.
  3. Apply the sizing formulas for the three phases:
        A. quantize      -> one block + calibration activations
        B. FP16 baseline -> the whole 16-bit model
        C. serve AWQ     -> the 4-bit model + KV cache
  4. For each phase pick the cheapest (GPU type x count) from configs/gpus.yaml.

Every number printed is an ESTIMATE from formulas; the quantize-speed constant is a guess
until calibrated by a real GPU run (see docs/).
"""

def count_params(model) -> dict:
    """Exact parameter accounting from a (meta) skeleton."""
    import torch.nn as nn

    from .blocks import find_blocks, fused_experts, quantizable_linears

    name, blocks = find_blocks(model)
    seen = set()
    total = 0
    for p in model.parameters():
        if id(p) in seen:
            continue
        seen.add(id(p))
        total += p.numel()
    per_block, lin_total, exp_total, n_lin, transposed_experts = [], 0, 0, 0, 0
    for b in blocks:
        lin, _ = quantizable_linears(b, 128)
        exps = fused_experts(b)
        lp = sum(m.weight.numel() for m in lin.values())
        ep = sum(getattr(m, pn).numel() for _, pn, m in exps)
        transposed_experts += sum(1 for _, m in b.named_modules() if getattr(m, "is_transposed", False))
        per_block.append(sum(p.numel() for p in b.parameters()))
        lin_total += lp
        exp_total += ep
        n_lin += len(lin)
    block_total = sum(per_block)
    # tied embeddings: the head re-uses the embedding matrix -> count it once
    tie = getattr(model.config.get_text_config() if hasattr(model.config, "get_text_config") else model.config,
                  "tie_word_embeddings", False)
    out_emb, in_emb = model.get_output_embeddings(), model.get_input_embeddings()
    if tie and out_emb is not None and in_emb is not None and out_emb.weight is not in_emb.weight:
        total -= out_emb.weight.numel()
    return {
        "blocks_path": name,
        "n_blocks": len(blocks),
        "total_params": total,
        "block_params": block_total,
        "non_block_params": total - block_total,
        "max_block_params": max(per_block),
        "quant_linear_params": lin_total,
        "quant_expert_params": exp_total,
        "quantizable_params": lin_total + exp_total,
        "n_quant_linears": n_lin,
        "coverage_of_blocks": (lin_total + exp_total) / max(1, block_total),
        "transposed_expert_modules": transposed_experts,
        "has_nn_linear": any(isinstance(m, nn.Linear) for m in blocks[0].modules()),
    }


def formula_params(d: dict) -> dict:
    """Fallback when no skeleton can be built: standard decoder formulas from config fields."""
    h, L, inter = d["hidden"], d["layers"], d["intermediate"]
    hd = d["head_dim"] or h // d["heads"]
    attn = h * d["heads"] * hd * 2 + h * d["kv_heads"] * hd * 2
    if d["experts"]:
        mlp = d["experts"] * 3 * h * (d["moe_intermediate"] or inter)
    else:
        mlp = 3 * h * inter
    block = attn + mlp
    emb = d["vocab"] * h * (1 if d["tie_word_embeddings"] else 2)
    return {"blocks_path": "?", "n_blocks": L, "total_params": block * L + emb, "block_params": block * L,
            "non_block_params": emb, "max_block_params": block,
            "quant_linear_params": attn * L + (0 if d["experts"] else mlp * L),
            "quant_expert_params": mlp * L if d["experts"] else 0, "quantizable_params": block * L,
            "n_quant_linears": None, "coverage_of_blocks": 1.0, "transposed_expert_modules": 0,
            "has_nn_linear": True, "estimated_from_formula": True}


def _pick(vram_gb: float, gpus: list[dict], allowed=(1, 2, 3, 4, 5, 6, 7, 8)):
    """Cheapest (gpu, count) whose usable memory (90%) holds vram_gb, with count in `allowed`."""
    options = []
    for g in gpus:
        need = max(1, math.ceil(vram_gb / (0.9 * g["vram_gb"])))
        n = next((a for a in allowed if a >= need), None)
        if n is not None:
            options.append({"gpu": g["name"], "count": n, "usd_per_hr": round(n * g["usd_per_hr"], 2),
                            "speed": g.get("speed", 1.0)})
    options.sort(key=lambda o: (o["usd_per_hr"], o["count"]))
    return options


def estimate(counts: dict, dims: dict, ckpt_gb: float | None = None, n_samples: int = 128,
             seq_len: int = 512, context: int = 8192, batch: int = 1, gpus_cfg: dict | None = None) -> dict:
    gpus_cfg = gpus_cfg or load_gpus()
    gpus = gpus_cfg["gpus"]
    P = counts["total_params"] / 1e9
    Pq = counts["quantizable_params"] / 1e9
    fp16_gb = 2 * P
    awq_gb = 0.52 * Pq + 2 * (P - Pq)
    block_gb = 2 * counts["max_block_params"] / 1e9
    width = max(dims["intermediate"] or 0, (dims["experts_per_tok"] or 0) * (dims["moe_intermediate"] or 0),
                dims["hidden"] or 0)
    calib_gb = n_samples * seq_len * width * 2 / 1e9
    vram_quant = 2 * block_gb + 6 * calib_gb + 2
    vram_fp16 = 1.2 * fp16_gb
    kv_width = dims.get("kv_cache_width") or 2 * (dims["kv_heads"] or 0) * (dims["head_dim"] or 0)
    kv_gb = (dims["layers"] or 0) * kv_width * context * batch * 2 / 1e9
    vram_serve = 1.15 * (awq_gb + kv_gb)
    ckpt_gb = ckpt_gb if ckpt_gb is not None else fp16_gb
    disk_gb = ckpt_gb + awq_gb + 20
    ram_gb = max(16, 3 * block_gb + 2 * calib_gb + 8)
    download_h = ckpt_gb * 1000 / DOWNLOAD_MB_S / 3600

    phases = {}
    # A: one block must fit ONE GPU (the pipeline does not split a block across cards).
    # B: transformers device_map="auto" spreads layers over any number of GPUs.
    # C: vLLM tensor parallelism wants 1, 2, 4 or 8 GPUs.
    allowed = {"A_quantize": (1,), "B_fp16_eval": (1, 2, 3, 4, 5, 6, 7, 8), "C_serve_awq": (1, 2, 4, 8)}
    for key, vram in (("A_quantize", vram_quant), ("B_fp16_eval", vram_fp16), ("C_serve_awq", vram_serve)):
        opts = _pick(vram, gpus, allowed[key])
        best = opts[0] if opts else None
        if key == "A_quantize" and best:
            hours = P * QUANT_MIN_PER_BPARAM_A100 / 60 / best["speed"] + download_h + 0.5
        elif key == "B_fp16_eval" and best:
            hours = 0.3 + P / 100 + download_h * 0          # weights already on disk from phase A
        else:
            hours = 0.3
        phases[key] = {
            "vram_gb": round(vram, 1),
            "best": best,
            "alternatives": opts[1:4],
            "hours_est": round(hours, 2) if best else None,
            "cost_usd_est": round(best["usd_per_hr"] * hours * 1.25, 2) if best else None,
            "feasible_single_node": bool(opts),
        }
    return {
        "params_b": round(P, 3),
        "quantizable_params_b": round(Pq, 3),
        "fp16_gb": round(fp16_gb, 2),
        "awq_gb": round(awq_gb, 2),
        "compression_x": round(fp16_gb / awq_gb, 2) if awq_gb else None,
        "checkpoint_gb": round(ckpt_gb, 2),
        "block_gb": round(block_gb, 3),
        "calib_act_gb": round(calib_gb, 3),
        "kv_cache_gb": round(kv_gb, 3),
        "context": context,
        "disk_gb": round(disk_gb, 1),
        "cpu_ram_gb": round(ram_gb, 1),
        "download_hours": round(download_h, 2),
        "phases": phases,
        "prices_checked": gpus_cfg.get("checked"),
        "price_source": gpus_cfg.get("source"),
        "note": "ESTIMATES. Quantize speed constant is uncalibrated until a real GPU run; prices change monthly.",
    }


def native_size_gb(counts: dict, dtype_bytes: int, group_size: int = 128) -> float:
    """Exact size of OUR native output: 4-bit codes + per-group (scale in run dtype + 1-byte zero),
    everything outside the quantized weights kept in the run dtype (fp32 on CPU, bf16/fp16 on GPU)."""
    pq, p = counts["quantizable_params"], counts["total_params"]
    g = group_size if group_size > 0 else 1
    return (pq * 0.5 + pq / g * (dtype_bytes + 1) + (p - pq) * dtype_bytes) / 1e9


def checkpoint_size_gb(model_id: str, revision: str = "main") -> float | None:
    p = Path(model_id).expanduser()
    try:
        if p.is_dir():
            files = list(p.glob("*.safetensors")) or list(p.glob("*.bin"))
            return sum(f.stat().st_size for f in files) / 1e9 if files else None
        from huggingface_hub import HfApi
        info = HfApi().model_info(model_id, revision=revision, files_metadata=True)
        sizes = [s.size for s in info.siblings if s.rfilename.endswith(".safetensors") and s.size]
        if not sizes:
            sizes = [s.size for s in info.siblings if s.rfilename.endswith(".bin") and s.size]
        return sum(sizes) / 1e9 if sizes else None
    except Exception:
        return None


def analyze_model(model_id: str, revision: str = "main", trust_remote_code: bool = False,
                  n_samples: int = 128, seq_len: int = 512, context: int = 8192, log=print) -> dict:
    import torch

    from .model_io import already_quantized_method, build_skeleton, checkpoint_is_fp8, load_hf_config

    config = load_hf_config(model_id, trust_remote_code)
    dims = config_dims(config)
    try:
        model = build_skeleton(model_id, torch.bfloat16, trust_remote_code)
        counts = count_params(model)
        del model
    except Exception as e:                                   # custom code that will not build, etc.
        log(f"[inspect] skeleton build failed ({type(e).__name__}: {str(e)[:160]}) -> formula estimate")
        counts = formula_params(dims)
    est = estimate(counts, dims, checkpoint_size_gb(model_id, revision), n_samples, seq_len, context)

    verdict, reasons = "PASS", []
    aq = already_quantized_method(config)
    if aq:
        verdict, reasons = "FAIL", [f"checkpoint is already quantized ({aq}). Use the original 16-bit/FP8 weights."]
    if counts["coverage_of_blocks"] < 0.5 and verdict != "FAIL":
        verdict = "WARN"
        reasons.append(f"only {counts['coverage_of_blocks']:.0%} of block weights are quantizable "
                       "(non-Linear compute or transposed experts) -> small memory saving")
    if counts.get("transposed_expert_modules"):
        reasons.append("some expert modules store transposed weights; they stay 16-bit")
    if checkpoint_is_fp8(config):
        reasons.append("FP8 checkpoint: dequantized to 16-bit block by block while loading (supported)")
    if not est["phases"]["B_fp16_eval"]["feasible_single_node"]:
        reasons.append("FP16 baseline does not fit one 8-GPU node -> skip it (--skip-fp16) and compare "
                       "against published scores")
    return {"model": model_id, "revision": revision, "verdict": verdict, "reasons": reasons,
            "dims": dims, "counts": counts, "estimate": est}

    lines = [

Plain words:

_EXPERT_PAIRS = [("w1", "w3", "w2"), ("gate_proj", "up_proj", "down_proj")]
_RENAMES = [(".mlp.", ".block_sparse_moe."), (".mlp.", ".feed_forward.")]


class WeightStore:
    """Reads individual tensors from a checkpoint folder on demand."""

    def __init__(self, path: Path | str):
        self.path = Path(path)
        self.key_to_file: dict[str, str] = {}
        self._handles: dict[str, object] = {}
        self._bin_cache: dict[str, dict] = {}
        idx = self.path / "model.safetensors.index.json"
        st_files = sorted(glob.glob(str(self.path / "*.safetensors")))
        if idx.exists():
            self.key_to_file = {k: str(self.path / v) for k, v in json.loads(idx.read_text())["weight_map"].items()}
            self.kind = "safetensors"
        elif st_files:
            from safetensors import safe_open
            for f in st_files:
                with safe_open(f, framework="pt") as h:
                    for k in h.keys():
                        self.key_to_file[k] = f
            self.kind = "safetensors"
        else:
            bidx = self.path / "pytorch_model.bin.index.json"
            if bidx.exists():
                wmap = json.loads(bidx.read_text())["weight_map"]
                self.key_to_file = {k: str(self.path / v) for k, v in wmap.items()}
            else:
                for f in sorted(glob.glob(str(self.path / "*.bin"))):
                    sd = torch.load(f, map_location="cpu", mmap=True, weights_only=True)
                    self._bin_cache[f] = sd
                    for k in sd:
                        self.key_to_file[k] = f
            self.kind = "bin"
        if not self.key_to_file:
            raise FileNotFoundError(f"No *.safetensors or *.bin weights found in {self.path}")

    def keys(self):
        return self.key_to_file.keys()

    def has(self, key: str) -> bool:
        return key in self.key_to_file

    def _raw(self, key: str) -> torch.Tensor:
        f = self.key_to_file[key]
        if self.kind == "safetensors":
            if f not in self._handles:
                from safetensors import safe_open
                self._handles[f] = safe_open(f, framework="pt")
            return self._handles[f].get_tensor(key)
        if f not in self._bin_cache:
            self._bin_cache[f] = torch.load(f, map_location="cpu", mmap=True, weights_only=True)
        return self._bin_cache[f][key]

    def get(self, key: str) -> torch.Tensor:
        """One tensor, FP8 block-dequantized to float32 if needed."""
        t = self._raw(key)
        if t.dtype in (getattr(torch, "float8_e4m3fn", None), getattr(torch, "float8_e5m2", None)):
            scale_key = key + "_scale_inv" if key.endswith("weight") else key.replace(".weight", ".weight_scale_inv")
            t = t.float()
            if self.has(scale_key):
                s = self._raw(scale_key).float()
                bo = -(-t.shape[0] // s.shape[0])          # block size along rows (128 for DeepSeek)
                bi = -(-t.shape[1] // s.shape[1])
                s = s.repeat_interleave(bo, 0)[: t.shape[0]].repeat_interleave(bi, 1)[:, : t.shape[1]]
                t = t * s
        return t

    # --- map a model parameter name to checkpoint tensor(s) -------------------
    def resolve(self, model_key: str) -> torch.Tensor:
        for cand in self._candidates(model_key):
            if self.has(cand):
                return self.get(cand)
        fused = self._fused_expert(model_key)
        if fused is not None:
            return fused
        raise KeyError(model_key)

    def _candidates(self, key: str):
        yield key
        for new, old in _RENAMES:
            if new in key:
                yield key.replace(new, old)

    def _fused_expert(self, key: str) -> torch.Tensor | None:
        m = re.match(r"(.*\.experts)\.(gate_up_proj|down_proj|up_proj)$", key)
        if not m:
            return None
        base, kind = m.groups()
        for prefix in self._candidates(base):
            for g_name, u_name, d_name in _EXPERT_PAIRS:
                first = f"{prefix}.0.{g_name}.weight"
                if not self.has(first):
                    continue
                n = 0
                while self.has(f"{prefix}.{n}.{g_name}.weight"):
                    n += 1
                if kind == "gate_up_proj":
                    gate = torch.stack([self.get(f"{prefix}.{e}.{g_name}.weight") for e in range(n)])
                    up = torch.stack([self.get(f"{prefix}.{e}.{u_name}.weight") for e in range(n)])
                    return torch.cat([gate, up], dim=1)
                name = d_name if kind == "down_proj" else u_name
                return torch.stack([self.get(f"{prefix}.{e}.{name}.weight") for e in range(n)])
        return None

def materialize(module: nn.Module, prefix: str, store: WeightStore, device, dtype,
                skip_prefixes: tuple[str, ...] = ()) -> list[str]:
    """Fill every meta parameter of `module` from the checkpoint. Returns names that were missing."""
    missing = []
    for name, p in list(module.named_parameters()) + list(module.named_buffers()):
        full = prefix + name
        if any(full.startswith(s) for s in skip_prefixes):
            continue
        is_meta = p.device.type == "meta"
        try:
            value = store.resolve(full)
        except KeyError:
            if is_meta:
                missing.append(full)
            elif p.device != torch.device(device):
                _set_tensor(module, name, p.data, device, p.dtype if not p.is_floating_point() else dtype)
            continue
        _set_tensor(module, name, value, device, dtype)
    return missing


def _module_to_meta(module: nn.Module) -> None:
    """Release memory: turn every tensor of `module` back into a meta tensor."""
    module.to_empty(device="meta")

class ModelSource:
    """Hands out one decoder block at a time.

    mode='stream': skeleton on meta + per-tensor reads (RAM ~ one block).
    mode='full'  : transformers.from_pretrained on CPU, blocks moved to GPU one by one
                   (fallback when the checkpoint layout cannot be mapped; RAM ~ model size).
    """

    def __init__(self, path: Path, dtype: torch.dtype, trust_remote_code: bool = False,
                 mode: str = "auto", log=print):
        self.path, self.dtype, self.trust_remote_code, self.log = Path(path), dtype, trust_remote_code, log
        self.config = load_hf_config(path, trust_remote_code)
        self.is_fp8 = checkpoint_is_fp8(self.config)
        self.mode = mode
        if mode in ("auto", "stream"):
            self.model = build_skeleton(path, dtype, trust_remote_code)
            self.store = WeightStore(path)
            self.blocks_name, self.blocks = find_blocks(self.model)
            if mode == "auto" and not self._layout_streamable():
                self.log("[model_io] checkpoint keys do not match the model layout -> FULL CPU LOAD fallback "
                         "(needs CPU RAM >= model size).")
                self.mode = "full"
            else:
                self.mode = "stream"
        if self.mode == "full":
            self.model = self._full_load()
            self.store = None
            self.blocks_name, self.blocks = find_blocks(self.model)
        self.log(f"[model_io] mode={self.mode}  blocks={self.blocks_name} x{len(self.blocks)}  fp8_ckpt={self.is_fp8}")

    def _layout_streamable(self) -> bool:
        """Check that every tensor of block 0 and the non-block parts can be found in the checkpoint."""
        try:
            for name, p in self.model.named_parameters():
                if name.startswith(self.blocks_name + ".") and not name.startswith(self.blocks_name + ".0."):
                    continue
                if self.store.has(name):
                    continue
                if self.tied and name.endswith("lm_head.weight"):
                    continue
                self.store.resolve(name)               # raises KeyError if not resolvable
            return True
        except KeyError as e:
            self.log(f"[model_io] unresolvable key: {e}")
            return False

    @property
    def tied(self) -> bool:
        cfg = self.config.get_text_config() if hasattr(self.config, "get_text_config") else self.config
        return bool(getattr(cfg, "tie_word_embeddings", False))

    def _full_load(self):
        from transformers import AutoModelForCausalLM

        kwargs = dict(dtype=self.dtype, trust_remote_code=self.trust_remote_code, low_cpu_mem_usage=True)
        if self.is_fp8:
            from transformers import FineGrainedFP8Config
            kwargs["quantization_config"] = FineGrainedFP8Config(dequantize=True)
        model = AutoModelForCausalLM.from_pretrained(str(self.path), **kwargs)
        model.eval()
        force_eager_experts(model)
        return model

    # non-block = embeddings, final norm, lm_head, rotary tables ...
    def _non_block_modules(self):
        b = self.blocks_name
        for name, mod in self.model.named_modules():
            if name == b or name.startswith(b + "."):
                continue
            yield name, mod

    def load_non_block(self, device) -> None:
        if self.mode == "stream":
            missing = materialize(self.model, "", self.store, device, self.dtype,
                                  skip_prefixes=(self.blocks_name + ".",))
            if self.tied:
                self._retie()
                missing = [m for m in missing if not m.endswith("lm_head.weight")]
            if missing:
                raise KeyError(f"Missing non-block weights in checkpoint: {missing[:5]}")
        for _, mod in self._non_block_modules():
            for n, p in list(mod._parameters.items()):
                if p is not None and p.device.type != "meta":
                    mod._parameters[n] = nn.Parameter(p.data.to(device), requires_grad=False)
            for n, buf in list(mod._buffers.items()):
                if buf is not None:
                    mod._buffers[n] = buf.to(device)
        if self.tied:
            self._retie()

    def _retie(self) -> None:
        out = self.model.get_output_embeddings()
        inp = self.model.get_input_embeddings()
        if out is not None and inp is not None:
            out.weight = inp.weight

    def unload_non_block(self) -> None:
        """Free embeddings/lm_head memory while blocks are being processed."""
        target = "meta" if self.mode == "stream" else "cpu"
        for _, mod in self._non_block_modules():
            for n, p in list(mod._parameters.items()):
                if p is None:
                    continue
                t = torch.empty_like(p, device="meta") if target == "meta" else p.data.to("cpu")
                mod._parameters[n] = nn.Parameter(t, requires_grad=False)

    def load_block(self, i: int, device) -> nn.Module:
        block = self.blocks[i]
        if self.mode == "stream":
            missing = materialize(block, f"{self.blocks_name}.{i}.", self.store, device, self.dtype)
            if missing:
                raise KeyError(f"Block {i}: weights missing from checkpoint: {missing[:5]}")
        block.to(device)
        return block

    def unload_block(self, i: int) -> None:
        if self.mode == "stream":
            _module_to_meta(self.blocks[i])
        else:
            self.blocks[i].to("cpu")

    def non_block_state_dict(self) -> dict[str, torch.Tensor]:
        """Original (unquantized) weights outside the blocks, as CPU tensors, for saving."""
        out = {}
        for name, p in self.model.named_parameters():
            if name.startswith(self.blocks_name + "."):
                continue
            if self.mode == "stream":
                try:
                    t = self.store.resolve(name)
                except KeyError:
                    if self.tied and name.endswith("lm_head.weight"):
                        continue
                    raise
            else:
                t = p.detach().cpu()
            out[name] = (t.to(self.dtype) if t.is_floating_point() else t).contiguous()
        return out

"""
pipeline.py — quantize a whole model, ONE decoder block at a time.

Plain words, the loop:
  1. Tokenize calibration text -> (n_samples, seq_len) tokens.
  2. Run embeddings and stop right before block 0 ("Catcher") -> inputs of block 0.
  3. For block i = 0 .. L-1:
       a. load block i's weights (only this block is on the GPU)
       b. run it once with hooks: record each Linear's input; Linears that receive the very
          same tensor form a "group" (q/k/v, gate/up, ...). MoE experts record their routed tokens.
       c. AWQ scale search per group, apply the scales (fold 1/s upstream when possible)
       d. AWQ clip search per Linear
       e. replace each Linear with a 4-bit AwqLinear (experts -> AwqExpertsWeight)
       f. run the quantized block -> block error; outputs become inputs of block i+1
       g. save block i to disk + progress file  (so a killed pod can --resume here)

class _Stop(Exception):

class _Catcher(nn.Module):
    """Stands in for block 0: stores its inputs, then stops the forward pass."""

    def __init__(self, block: nn.Module):
        super().__init__()
        self.block = block
        self.hidden: list[torch.Tensor] = []
        self.kwargs: dict | None = None

    def __getattr__(self, name):
        try:
            return super().__getattr__(name)
        except AttributeError:
            return getattr(self._modules["block"], name)   # e.g. `.attention_type` read by the model

    def forward(self, hidden_states, *args, **kwargs):
        self.hidden.append(hidden_states.detach())
        if self.kwargs is None:
            self.kwargs = kwargs
        raise _Stop


def _clean_kwargs(kw: dict) -> dict:
    kw = dict(kw)
    for k in ("past_key_values", "past_key_value", "layer_past"):
        kw.pop(k, None)
    kw["use_cache"] = False
    return kw


@torch.no_grad()
def capture_block0_inputs(model: nn.Module, blocks: nn.ModuleList, batches, device):
    """batches: iterable of model-input dicts. Returns (inputs (N, T, h), layer_kwargs)."""
    is_hf = hasattr(model, "config") and hasattr(model, "generate")
    extra = {"use_cache": False} if is_hf else {}
    catcher = _Catcher(blocks[0])
    blocks[0] = catcher
    try:
        for batch in batches:
            batch = {k: (v.to(device) if torch.is_tensor(v) else v) for k, v in batch.items()}
            try:
                model(**batch, **extra)
            except _Stop:
                pass
    finally:
        blocks[0] = catcher.block
    kw = _clean_kwargs(catcher.kwargs or {}) if is_hf else dict(catcher.kwargs or {})
    return torch.cat(catcher.hidden, dim=0), kw


@torch.no_grad()
def run_block(block: nn.Module, inps: torch.Tensor, kwargs: dict, bs: int) -> torch.Tensor:
    outs = []
    for i in range(0, inps.shape[0], bs):
        o = block(inps[i:i + bs], **kwargs)
        outs.append(o[0] if isinstance(o, (tuple, list)) else o)
    return torch.cat(outs, dim=0)


class _ExpertRecorder:
    """While active, F.linear calls whose weight is expert e of a fused 3-D parameter are recorded."""

    def __init__(self, experts):
        self.map = {}
        self.feats = defaultdict(list)
        for mod_name, pname, mod in experts:
            p = getattr(mod, pname)
            for e in range(p.shape[0]):
                self.map[p[e].data_ptr()] = (f"{mod_name}.{pname}", e, tuple(p.shape[1:]))
        self._orig = None

    def __enter__(self):
        self._orig = F.linear
        rec = self

        def linear(input, weight, bias=None):
            hit = rec.map.get(weight.data_ptr()) if weight.dim() == 2 else None
            if hit is not None and tuple(weight.shape) == hit[2]:
                rec.feats[(hit[0], hit[1])].append(input.detach().reshape(-1, input.shape[-1]))
            return rec._orig(input, weight, bias)

        torch.nn.functional.linear = linear
        return self

    def __exit__(self, *exc):
        torch.nn.functional.linear = self._orig


@torch.no_grad()
def collect(block, inps, kwargs, bs, linears: dict, experts):
    """Run the FP block once. Returns (fp_outputs, {name: input tensor list}, groups, expert_feats)."""
    feats, first_key, handles = defaultdict(list), {}, []

    def make_hook(name):
        def hook(mod, args, kw, out):
            x = args[0] if args else kw.get("input")
            if name not in first_key:
                first_key[name] = (x.data_ptr(), tuple(x.shape), x.stride())
            feats[name].append(x.detach().reshape(-1, x.shape[-1]))
        return hook

    for name, m in linears.items():
        handles.append(m.register_forward_hook(make_hook(name), with_kwargs=True))
    rec = _ExpertRecorder(experts)
    try:
        with rec:
            outs = run_block(block, inps, kwargs, bs)
    finally:
        for h in handles:
            h.remove()
    groups: OrderedDict[tuple, list[str]] = OrderedDict()
    for name in linears:                      # module order = execution order for standard blocks
        if name in first_key:
            groups.setdefault(first_key[name], []).append(name)
    return outs, feats, list(groups.values()), rec.feats


def _fold(block, target, s: torch.Tensor):
    """Absorb x/s into the op that produces x (so no runtime cost)."""
    kind, name = target
    mod = block.get_submodule(name)
    w = mod.weight.data
    hp = torch.float64 if w.dtype == torch.float64 else torch.float32     # compute in >= fp32
    s = s.to(w.device, hp)
    if kind == "norm":
        mod.weight.data = (w.to(hp) / s).to(w.dtype)
    elif kind == "norm_offset":                    # Gemma RMSNorm multiplies by (1 + w)
        mod.weight.data = ((1 + w.to(hp)) / s - 1).to(w.dtype)
    elif kind == "linear_out":                     # previous Linear: scale its output rows
        mod.weight.data = (w.to(hp) / s.view(-1, 1)).to(w.dtype)
    if getattr(mod, "bias", None) is not None:
        mod.bias.data = (mod.bias.data.to(hp) / s).to(mod.bias.dtype)


@torch.no_grad()
def quantize_block(block: nn.Module, idx: int, inps: torch.Tensor, kwargs: dict, rc: RunConfig,
                   family: str, log) -> tuple[torch.Tensor, dict, dict]:
    q, sc = rc.quant, rc.search
    bs = rc.calib.batch_size
    linears, skipped = quantizable_linears(block, q.group_size, q.skip_modules)
    experts = fused_experts(block) if q.quantize_experts else []
    t0 = time.time()
    outs_fp, feats, groups, expert_feats = collect(block, inps, kwargs, bs, linears, experts)
    report = {"block": idx, "groups": [], "experts": {}, "skipped": skipped}

    # ---- (c) scale search for every group, then apply -------------------------------------
    inv_s_of: dict[str, torch.Tensor] = {}
    group_x: dict[str, torch.Tensor] = {}
    plans = []
    for names in groups:
        x = torch.cat(feats[names[0]], dim=0)
        for n in names:
            feats.pop(n, None)
        target = fold_target(block, names, family) if q.fold_scales == "auto" else None
        searchable = target is not None or q.fold_scales == "never" or family not in FOLD_FAMILIES
        ws = [linears[n].weight.data for n in names]
        if searchable:
            res = search_scale(ws, [linears[n].bias for n in names], x, q.w_bit, q.group_size,
                               q.zero_point, sc.n_grid, sc.duo_scaling, sc.max_search_tokens)
        else:
            res = None
        plans.append((names, target, res, x))
        report["groups"].append({
            "linears": names,
            "fold": None if target is None else f"{target[0]}:{target[1]}",
            "mode": "folded" if target else ("inv_s" if searchable else "no-scale (export-compatible)"),
            "ratio": None if res is None or res["ratio"] is None else round(res["ratio"], 3),
            "loss_awq": None if res is None else res["loss"],
            "loss_rtn": None if res is None else res["loss_rtn"],
        })
    for names, target, res, x in plans:
        if res is not None and res["ratio"] is not None:
            s = res["scales"].to(x.device)
            for n in names:
                w = linears[n].weight
                w.data = (w.data.float() * s.view(1, -1)).to(w.dtype)
            if target is not None:
                _fold(block, target, s)
            else:
                for n in names:
                    inv_s_of[n] = (1.0 / s)
            x = (x.float() / s.view(1, -1)).to(x.dtype)
        for n in names:
            group_x[n] = x

    # ---- (d) clip search + (e) quantize ------------------------------------------------------
    for name, lin in linears.items():
        if name not in group_x:
            skipped[name] = "never executed during calibration (kept 16-bit)"
            continue
        if sc.clip and allow_clip(name):
            mv = search_clip(lin.weight.data, group_x[name], q.w_bit, q.group_size, q.zero_point,
                             sc.clip_grid, sc.max_shrink, sc.clip_tokens)
            lin.weight.data = apply_clip(lin.weight.data, mv)
        new = AwqLinear.from_float(lin, q.w_bit, q.group_size, q.zero_point, inv_s_of.get(name))
        parent_name, _, attr = name.rpartition(".")
        setattr(block.get_submodule(parent_name) if parent_name else block, attr, new)
    group_x.clear()

    # ---- MoE fused experts: per-expert AWQ (scale kept inside, never folded) -------------------
    for mod_name, pname, mod in experts:
        key = f"{mod_name}.{pname}"
        p = getattr(mod, pname)
        E, out_f, in_f = p.shape
        if in_f % (in_f if q.group_size <= 0 else q.group_size) != 0:
            skipped[key] = "expert in_features not divisible by group_size"
            continue
        qmod = AwqExpertsWeight(E, out_f, in_f, q.w_bit, q.group_size, dtype=p.dtype, device=p.device)
        stats = {"experts": E, "with_tokens": 0, "tokens_min": None, "tokens_max": 0}
        for e in range(E):
            w = p[e].data
            xs = expert_feats.get((key, e))
            if xs:
                x = torch.cat(xs, dim=0)
                n_tok = x.shape[0]
                stats["with_tokens"] += 1
                stats["tokens_max"] = max(stats["tokens_max"], n_tok)
                stats["tokens_min"] = n_tok if stats["tokens_min"] is None else min(stats["tokens_min"], n_tok)
                res = search_scale([w], [None], x, q.w_bit, q.group_size, q.zero_point, sc.n_grid,
                                   sc.duo_scaling, sc.max_search_tokens)
                inv = None
                if res["ratio"] is not None:
                    s = res["scales"].to(w.device)
                    w = (w.float() * s.view(1, -1)).to(w.dtype)
                    x = (x.float() / s.view(1, -1)).to(x.dtype)
                    inv = 1.0 / s
                if sc.clip:
                    w = apply_clip(w, search_clip(w, x, q.w_bit, q.group_size, q.zero_point,
                                                  sc.clip_grid, sc.max_shrink, sc.clip_tokens))
                qmod.set_expert(e, w, inv, q.zero_point)
            else:                                   # expert never routed to: plain RTN
                qmod.set_expert(e, w, None, q.zero_point)
        mod._parameters.pop(pname, None)      # a Parameter slot cannot hold a Module
        setattr(mod, pname, qmod)
        report["experts"][key] = stats
    expert_feats.clear()

    # ---- (f) quantized forward -> block error + next inputs ----------------------------------
    outs_q = run_block(block, inps, kwargs, bs)
    denom = outs_fp.float().pow(2).mean().item() + 1e-12
    report["block_rel_mse"] = (outs_q.float() - outs_fp.float()).pow(2).mean().item() / denom
    report["seconds"] = round(time.time() - t0, 2)
    meta = {
        "linears": {n: {"inv_s": n in inv_s_of} for n, m in block.named_modules() if isinstance(m, AwqLinear)},
        "experts": {n: {"shape": [m.num_experts, m.out_features, m.in_features]}
                    for n, m in block.named_modules() if isinstance(m, AwqExpertsWeight)},
        "skipped": skipped,
    }
    nxt = outs_fp if sc.propagate == "fp" else outs_q
    del outs_q
    return nxt, report, meta

plugin.py — quantize YOUR OWN PyTorch model (not on the Hugging Face Hub, not a transformers class).

Write a small file, e.g. my_plugin.py, with three functions and point `plugin:` in run.yaml at it:

    def load():                                   # -> (model, tokenizer_or_None), FP weights loaded
        ...

    def calib_batches(tokenizer, n_samples, seq_len, batch_size):
        # yield dicts of keyword arguments for model(**batch), batch_size samples each
        ...

Requirements (honest): the block's heavy compute must be nn.Linear layers, and each block must be
callable as block(hidden_states, **kwargs) returning a tensor (or a tuple whose first item is it).
The plugin model is loaded fully in CPU RAM (no streaming): fine up to ~tens of GB.

from __future__ import annotations

def load_plugin(path: str | Path):
    path = Path(path)
    spec = importlib.util.spec_from_file_location(f"awq_user_plugin_{path.stem}", path)
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)
    for fn in ("load", "blocks", "calib_batches"):
        if not hasattr(mod, fn):
            raise AttributeError(f"plugin {path} must define `{fn}()`")
    return mod


class PluginSource:
    """Same interface as model_io.ModelSource, backed by the user's plugin."""

    mode = "full"
    tied = False

    def __init__(self, rc, log=print):

        self.mod = load_plugin(rc.plugin)
        self.model, self.tokenizer = self.mod.load()
        self.model.eval()
        self.blocks = self.mod.blocks(self.model)
        self.blocks_name = next(n for n, m in self.model.named_modules() if m is self.blocks)
        self.log(f"[plugin] {rc.plugin}: blocks={self.blocks_name} x{len(self.blocks)}")

    def _non_block(self):
        b = self.blocks_name
        for name, mod in self.model.named_modules():
            if name == b or name.startswith(b + "."):
                continue
            yield mod

    def load_non_block(self, device):
        for mod in self._non_block():
            for n, p in list(mod._parameters.items()):

                    mod._buffers[n] = b.to(device)

    def unload_non_block(self):
        self.load_non_block("cpu")

        self.blocks[i].to("cpu")

    def calib_batches(self, n_samples, seq_len, batch_size):
        return self.mod.calib_batches(self.tokenizer, n_samples, seq_len, batch_size)

    def non_block_state_dict(self):

                if not k.startswith(b)}

"""
quantizer.py — the arithmetic of 4-bit group quantization. No AWQ yet, just numbers.

Plain words:
  * A weight matrix W has shape (out_features, in_features).
  * We cut every row into groups of `group_size` consecutive input channels.
  * Each group gets one `scale` (and one `zero` in asymmetric mode).
  * Every weight becomes an integer q in [0, 15]:      q = round(w / scale) + zero
  * To get the weight back (dequantize):               w ≈ (q - zero) * scale
  * Two 4-bit integers are packed into one uint8 byte, so storage is 0.5 byte/weight.

`fake_quant` = quantize then immediately dequantize. It returns a float matrix that
already contains the rounding error — that is what the AWQ search measures.
"""
from __future__ import annotations

import torch


def _group(in_features: int, group_size: int) -> int:
    """group_size=-1 means one group per whole row (per-channel)."""
    g = in_features if group_size <= 0 else group_size
    if in_features % g != 0:
        raise ValueError(f"in_features={in_features} is not divisible by group_size={g}")
    return g


@torch.no_grad()
def compute_qparams(w: torch.Tensor, w_bit: int = 4, group_size: int = 128, zero_point: bool = True):
    """Return (scales, zeros), both float32 with shape (out, n_groups).

    Asymmetric (zero_point=True): use min and max of each group  -> the 16 levels cover [min, max].
    Symmetric  (zero_point=False): use max|w| of each group       -> levels cover [-max, +max], zero fixed at 8.
    """
    out_f, in_f = w.shape
    g = _group(in_f, group_size)
    wg = w.float().reshape(out_f, in_f // g, g)
    qmax = 2 ** w_bit - 1                                   # 15 for 4-bit
    if zero_point:
        w_max = wg.amax(dim=-1)
        w_min = wg.amin(dim=-1)
        scales = (w_max - w_min).clamp(min=1e-5) / qmax
        zeros = (-torch.round(w_min / scales)).clamp(0, qmax)
    else:
        half = 2 ** (w_bit - 1)                             # 8 for 4-bit
        scales = wg.abs().amax(dim=-1).clamp(min=1e-5) / (half - 1)
        zeros = torch.full_like(scales, float(half))
    return scales, zeros


@torch.no_grad()
def quantize(w: torch.Tensor, scales: torch.Tensor, zeros: torch.Tensor,
             w_bit: int = 4, group_size: int = 128) -> torch.Tensor:
    """Float weights -> integer codes q in [0, 2^bits - 1] (uint8, shape (out, in))."""
    out_f, in_f = w.shape
    g = _group(in_f, group_size)
    wg = w.float().reshape(out_f, in_f // g, g)
    q = torch.round(wg / scales.unsqueeze(-1)) + zeros.unsqueeze(-1)
    q = q.clamp(0, 2 ** w_bit - 1)
    return q.reshape(out_f, in_f).to(torch.uint8)


def dequantize(q: torch.Tensor, scales: torch.Tensor, zeros: torch.Tensor,
               group_size: int = 128, dtype: torch.dtype = torch.float16) -> torch.Tensor:
    """Integer codes -> float weights:  w = (q - zero) * scale."""
    out_f, in_f = q.shape
    g = _group(in_f, group_size)
    qg = q.reshape(out_f, in_f // g, g).to(scales.dtype)
    w = (qg - zeros.to(scales.dtype).unsqueeze(-1)) * scales.unsqueeze(-1)
    return w.reshape(out_f, in_f).to(dtype)


@torch.no_grad()
def fake_quant(w: torch.Tensor, w_bit: int = 4, group_size: int = 128, zero_point: bool = True) -> torch.Tensor:
    """Quantize + dequantize in one go. Same shape and dtype as the input."""
    scales, zeros = compute_qparams(w, w_bit, group_size, zero_point)
    q = quantize(w, scales, zeros, w_bit, group_size)
    return dequantize(q, scales, zeros, group_size, dtype=w.dtype)


# ---------------------------------------------------------------------------
# Packing: two 4-bit codes per byte.  byte = low nibble (even column) | high nibble (odd column) << 4
# ---------------------------------------------------------------------------
def pack_int4(q: torch.Tensor) -> torch.Tensor:
    """(..., in) uint8 codes in [0,15] -> (..., in/2) uint8."""
    if q.shape[-1] % 2:
        raise ValueError("pack_int4 needs an even number of columns")
    q = q.to(torch.uint8)
    return (q[..., 0::2] | (q[..., 1::2] << 4)).contiguous()


def unpack_int4(p: torch.Tensor) -> torch.Tensor:
    """Inverse of pack_int4: (..., in/2) uint8 -> (..., in) uint8 codes."""
    low = p & 0x0F
    high = (p >> 4) & 0x0F
    return torch.stack([low, high], dim=-1).reshape(*p.shape[:-1], p.shape[-1] * 2)

"""
search.py — the AWQ algorithm itself (Lin et al. 2023, arXiv:2306.00978).

Plain words, scale search (`search_scale`):
  For a group of layers that read the same input x (e.g. q/k/v):
    1. importance of input channel j:   x_mean[j] = mean |x[:, j]|
    2. try ratio a = 0, 1/n, 2/n, ...:   s = x_mean^a / w_mean^(1-a)        (duo scaling)
                                         s = s / sqrt(max(s) * min(s))      (keep magnitudes sane)
    3. pretend-quantize the scaled weight and undo the scale:  W_test = Q(W * s) / s
    4. error = || x W^T - x W_test^T ||^2   (how much the layer output changed)
    5. keep the s with the smallest error.
  s = 1 (plain round-to-nearest) is always tried first, so on calibration data AWQ can never be
  worse than RTN — it only replaces RTN when some scale measurably lowers the error.

Plain words, clip search (`search_clip`):
  One huge weight in a group stretches that group's scale, wasting the 16 levels.
  Try shrinking each group's max |w| to 100%, 95%, ... 50% and keep the cut that minimises
  the group's output error. Skipped for q/k projections (attention scores are sensitive).
"""
from __future__ import annotations

import math

import torch

from .quantizer import fake_quant


def _chunks(n: int, size: int):
    for i in range(0, n, size):
        yield slice(i, min(i + size, n))


@torch.no_grad()
def _subsample(x: torch.Tensor, max_tokens: int, seed: int = 0) -> torch.Tensor:
    if max_tokens and x.shape[0] > max_tokens:
        g = torch.Generator(device="cpu").manual_seed(seed)
        idx = torch.randperm(x.shape[0], generator=g)[:max_tokens].to(x.device)
        return x.index_select(0, idx)
    return x


@torch.no_grad()
def search_scale(weights: list[torch.Tensor], biases: list[torch.Tensor | None], x: torch.Tensor,
                 w_bit: int, group_size: int, zero_point: bool, n_grid: int = 20,
                 duo_scaling: bool = True, max_tokens: int = 0, token_chunk: int = 4096):
    """weights: list of (out_i, in) matrices sharing input x (n, in).

    Returns dict(scales=(in,) float32, ratio=float or None (None = plain RTN won),
                 loss=float, loss_rtn=float, losses=list).
    """
    x = _subsample(x, max_tokens)
    dev, dt = weights[0].device, weights[0].dtype
    x = x.to(dev, dt)
    in_f = x.shape[-1]
    x_mean = x.abs().float().mean(0)                                     # (in,)

    if duo_scaling:
        wcat = torch.cat(weights, dim=0).float()
        g = in_f if group_size <= 0 else group_size
        wg = wcat.abs().view(-1, g)
        w_scale = (wg / (wg.amax(dim=1, keepdim=True) + 1e-6)).view(wcat.shape)
        w_mean = w_scale.mean(0)                                         # (in,)
        del wcat, wg, w_scale
    else:
        w_mean = None

    # output error of a candidate:  || x W^T - x W_test^T ||^2 = || x (W - W_test)^T ||^2
    # -> ONE matmul per candidate, computed chunk by chunk to bound memory (bias cancels).
    def outputs_error(test_weights):
        diffs = [(w_ref - w_t) for w_ref, w_t in zip(weights, test_weights)]
        err, count = 0.0, 0
        for sl in _chunks(x.shape[0], token_chunk):
            xb = x[sl]
            for d in diffs:
                err += (xb @ d.T).float().pow(2).sum().item()
                count += xb.shape[0] * d.shape[0]
        return err / max(count, 1)

    # candidate 0: s = 1 (plain round-to-nearest). AWQ only replaces it if a scale is better.
    loss_rtn = outputs_error([fake_quant(w, w_bit, group_size, zero_point) for w in weights])
    best = dict(loss=loss_rtn, ratio=None, scales=torch.ones(in_f, device=dev))
    losses = []
    for i in range(n_grid):
        ratio = i / n_grid
        if w_mean is not None:
            s = (x_mean.pow(ratio) / (w_mean.pow(1 - ratio) + 1e-4)).clamp(min=1e-4)
        else:
            s = x_mean.pow(ratio).clamp(min=1e-4)
        s = s / (s.max() * s.min()).sqrt()
        if not torch.isfinite(s).all():
            losses.append(math.inf)
            continue
        s_dt = s.to(dt)
        tests = [fake_quant(w * s_dt.view(1, -1), w_bit, group_size, zero_point) / s_dt.view(1, -1)
                 for w in weights]
        loss = outputs_error(tests)
        losses.append(loss)
        if loss < best["loss"]:
            best = dict(loss=loss, ratio=ratio, scales=s.clone())
    best["loss_rtn"] = loss_rtn
    best["losses"] = losses
    best["scales"] = best["scales"].float()
    return best


@torch.no_grad()
def search_clip(w: torch.Tensor, x: torch.Tensor, w_bit: int, group_size: int, zero_point: bool,
                clip_grid: int = 20, max_shrink: float = 0.5, n_tokens: int = 512,
                elem_budget: int = 2 ** 27) -> torch.Tensor:
    """Return best max|w| per (out, group) — shape (out, n_groups, 1). `w` is already scaled.
    `x` must already be divided by the AWQ scale (it is the input the scaled weight will see)."""
    out_f, in_f = w.shape
    g = in_f if group_size <= 0 else group_size
    ng = in_f // g
    # evenly spaced token subsample (official AWQ uses 512)
    if x.shape[0] > n_tokens:
        step = max(1, x.shape[0] // n_tokens)
        x = x[::step][:n_tokens]
    x = x.to(w.device, w.dtype)
    n = x.shape[0]
    xg = x.view(n, ng, g)                                                  # (n, ng, g)
    oc_batch = max(1, min(out_f, elem_budget // max(1, n * ng)))
    best_max_all = []
    for sl in _chunks(out_f, oc_batch):
        wb = w[sl].view(-1, ng, g)                                         # (ob, ng, g)
        # partial output of every group: out[o, t, k] = sum_j x[t, k, j] * w[o, k, j]  (batched matmul)
        org_out = torch.einsum("nkg,okg->onk", xg, wb)                     # (ob, n, ng)
        org_max = wb.abs().amax(dim=-1, keepdim=True)                      # (ob, ng, 1)
        best_max = org_max.clone()
        min_err = torch.full((wb.shape[0], ng), float("inf"), device=w.device)
        for i in range(int(max_shrink * clip_grid)):
            max_val = org_max * (1 - i / clip_grid)
            cur = torch.clamp(wb, -max_val, max_val)
            q = fake_quant(cur.reshape(wb.shape[0], in_f), w_bit, g, zero_point).view(-1, ng, g)
            cur_out = torch.einsum("nkg,okg->onk", xg, q)
            err = (cur_out - org_out).float().pow(2).mean(dim=1)           # (ob, ng)
            better = err < min_err
            min_err[better] = err[better]
            best_max[better] = max_val[better]
        best_max_all.append(best_max)                                      # (ob, ng, 1)
        del org_out, wb
    return torch.cat(best_max_all, dim=0)


@torch.no_grad()
def apply_clip(w: torch.Tensor, max_val: torch.Tensor) -> torch.Tensor:
    out_f, in_f = w.shape
    ng = max_val.shape[1]
    g = in_f // ng
    wg = w.view(out_f, ng, g)
    mv = max_val.to(w.dtype)
    return torch.clamp(wg, -mv, mv).view(out_f, in_f)

class Logger:
    """print() that also appends to a log file, with elapsed time."""

    def __init__(self, path: str | Path | None = None):
        self.t0 = time.time()
        self.path = Path(path) if path else None
        if self.path:
            self.path.parent.mkdir(parents=True, exist_ok=True)

    def __call__(self, *msg):
        line = f"[{time.time() - self.t0:8.1f}s] " + " ".join(str(m) for m in msg)
        print(line, flush=True)
        if self.path:
            with open(self.path, "a") as fh:
                fh.write(line + "\n")

04_verify.py — GATE 4. Is the quantized model sane before we spend time on full evaluation?

  * loads the quantized model ALONE first and measures its real footprint (weights actually allocated,
    and peak VRAM on GPU) — the honest version of the "VRAM drop" claim
  * size on disk vs. the formula estimate from 01_inspect_model
  * logits on 10 probe prompts vs. the original model: relative error + top-1 agreement
  * every packed layer decodes to finite numbers

    python scripts/04_verify.py --config configs/run.yaml
"""
import gc
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
import torch  # noqa: E402

from awq.cli import parser, run_config  # noqa: E402
from awq.evaluate import DEFAULT_PROMPTS, input_device, load_fp_model, model_bytes  # noqa: E402
from awq.awq_linear import AwqLinear  # noqa: E402
from awq.hardware import native_size_gb  # noqa: E402
from awq.model_io import load_quantized, resolve_model_path  # noqa: E402
from awq.utils import Logger, dir_size_gb, read_json, write_json  # noqa: E402

GATE_TOP1 = 0.75          # >= 75% of next-token predictions identical to the original model
GATE_SIZE_TOL = 0.15      # on-disk size within 15% of the formula estimate


@torch.no_grad()
def logits_for(model, tok):
    dev = input_device(model)
    outs = []
    for pr in DEFAULT_PROMPTS:
        ids = tok(pr, return_tensors="pt").input_ids.to(dev)
        outs.append(model(input_ids=ids, use_cache=False).logits[0].float().cpu())
    return outs


def main():
    p = parser(__doc__)
    p.add_argument("--skip-fp16", action="store_true", help="no FP16 comparison (model too big)")
    args = p.parse_args()
    rc = run_config(args)
    log = Logger(rc.work_dir / "verify.log")
    from transformers import AutoTokenizer

    qdir = rc.work_dir / "quantized"
    path = resolve_model_path(rc.model, rc.revision, rc.trust_remote_code)
    tok = AutoTokenizer.from_pretrained(str(qdir))
    out, gates = {}, {}

    if rc.device == "cuda":
        torch.cuda.empty_cache()
        torch.cuda.reset_peak_memory_stats()
    qm = load_quantized(qdir, rc.device)
    out["awq_weight_bytes"] = model_bytes(qm)
    if rc.device == "cuda":
        out["awq_load_peak_vram_gb"] = round(torch.cuda.max_memory_allocated() / 1e9, 3)
    out["awq_disk_gb"] = dir_size_gb(qdir)
    bad = [n for n, m in qm.named_modules()
           if isinstance(m, AwqLinear) and not torch.isfinite(m.dequant_weight()).all()]
    gates["all_layers_finite"] = not bad
    report = rc.work_dir / "model_report.json"
    if report.exists():
        counts = read_json(report)["counts"]
        dtype_bytes = torch.tensor([], dtype=rc.torch_dtype).element_size()
        est = native_size_gb(counts, dtype_bytes, rc.quant.group_size)   # formula for THIS run's dtype
        out["awq_gb_formula"] = round(est, 4)
        out["awq_gb_formula_16bit"] = read_json(report)["estimate"]["awq_gb"]
        out["size_vs_formula"] = round(out["awq_disk_gb"] / est, 3)
        gates["size_matches_formula"] = abs(out["size_vs_formula"] - 1) <= GATE_SIZE_TOL
    log(f"[verify] AWQ weights {out['awq_weight_bytes'] / 1e9:.3f} GB in memory, {out['awq_disk_gb']} GB on disk")
    q_logits = logits_for(qm, tok)
    del qm
    gc.collect()

    if not args.skip_fp16:
        fp = load_fp_model(path, rc.torch_dtype, rc.device, rc.trust_remote_code)
        if rc.device == "cpu":
            fp.to("cpu")
        out["fp16_weight_bytes"] = model_bytes(fp)
        f_logits = logits_for(fp, tok)
        del fp
        rel, agree, n = [], 0, 0
        for a, b in zip(f_logits, q_logits):
            rel.append(((a - b).norm() / a.norm()).item())
            agree += (a.argmax(-1) == b.argmax(-1)).sum().item()
            n += a.shape[0]
        out["logit_rel_err_mean"] = sum(rel) / len(rel)
        out["top1_agreement"] = agree / n
        out["memory_reduction_x"] = round(out["fp16_weight_bytes"] / out["awq_weight_bytes"], 3)
        gates["top1_agreement>=0.75"] = out["top1_agreement"] >= GATE_TOP1
        log(f"[verify] logit rel err {out['logit_rel_err_mean']:.4f} | top-1 agreement {out['top1_agreement']:.3f} "
            f"| weights {out['memory_reduction_x']}x smaller in memory")
    out["gates"] = gates
    out["pass"] = all(gates.values())
    write_json(rc.work_dir / "verify.json", out)
    for k, v in gates.items():
        log(f"[verify] {'PASS' if v else 'FAIL'}  {k}")
    log("[verify] PASS" if out["pass"] else "[verify] FAIL")
    sys.exit(0 if out["pass"] else 1)


if __name__ == "__main__":
    main()

#!/usr/bin/env python
"""
05_eval.py — the headline numbers for the quantized model + pass/fail gates vs. baseline.json.

  perplexity on eval.ppl_datasets (same windows as 02_baseline), generations side by side

def gate_limits(params_b: float):
    if params_b <= 3.5:
        return 0.10, 3.0, "<=3B"
    if params_b < 60:
        return 0.05, 1.5, "7-34B"
    return 0.03, 1.0, ">=70B"


def custom_accuracy(model, tok, path):
    rows = read_custom_jsonl(path)
    gens = generations(model, tok, [r["prompt"] for r in rows], max_new_tokens=64)
    hits = sum(1 for r, g in zip(rows, gens) if r["expected"].strip().lower() in g.lower())
    return hits / max(1, len(rows))


def main():
    p = parser(__doc__)
    p.add_argument("--no-lm-eval", action="store_true")
    p.add_argument("--no-gen", action="store_true")

    log = Logger(rc.work_dir / "eval.log")
    from transformers import AutoTokenizer

    if rc.device == "cuda":
        torch.cuda.reset_peak_memory_stats()

    if rc.device == "cuda":
        res["awq_peak_vram_gb"] = round(torch.cuda.max_memory_allocated() / 1e9, 3)
    if not args.no_gen:
        res["awq_generations"] = generations(model, tok, max_new_tokens=rc.eval.gen_max_new_tokens)
        res["awq_speed"] = speed(model, tok)
        log(f"[eval] awq speed {res['awq_speed']}  (reference dequant-per-call kernels; export for fast serving)")

        res["awq_custom_accuracy"] = custom_accuracy(model, tok, rc.eval.custom_jsonl)

        for d in rc.eval.ppl_datasets:
            fp, rtn, awq = base.get(f"fp16_ppl_{d}"), base.get(f"rtn_ppl_{d}"), res[f"awq_ppl_{d}"]
            if fp:
                res[f"awq_vs_fp16_{d}"] = (awq - fp) / fp
                gates[f"{d}: AWQ ppl within {ppl_gate:.0%} of FP16"] = res[f"awq_vs_fp16_{d}"] <= ppl_gate
            if rtn:
                res[f"rtn_vs_fp16_{d}"] = (rtn - fp) / fp if fp else None
                gates[f"{d}: AWQ ppl < RTN ppl"] = awq < rtn
        if base.get("fp16_weight_bytes"):
            res["weight_memory_reduction_x"] = round(base["fp16_weight_bytes"] / res["awq_weight_bytes"], 3)
        if base.get("fp16_lm_eval") and res.get("awq_lm_eval"):
            drops = []
            for task, m in res["awq_lm_eval"].items():
                key = "acc_norm" if "acc_norm" in m else "acc"
                if task in base["fp16_lm_eval"] and key in m:
                    drops.append(100 * (base["fp16_lm_eval"][task][key] - m[key]))
            if drops:

        if not args.no_gen:

                  f"max_new_tokens={rc.eval.gen_max_new_tokens}\n"]

                       f"**AWQ:**\n```\n{b.strip()}\n```\n"]
            (rc.work_dir / "generations.md").write_text("\n".join(md))
    else:
        log("[eval] no baseline.json -> run 02_baseline.py for comparisons and gates")
    res["gates"] = gates
    res["pass"] = bool(gates) and all(gates.values())
    write_json(rc.work_dir / "results.json", res)
    log("[eval] ---------------- RESULTS ----------------")
    for d in rc.eval.ppl_datasets:
        b = read_json(base_f) if base_f.exists() else {}
        fp, rtn = b.get(f"fp16_ppl_{d}", float("nan")), b.get(f"rtn_ppl_{d}", float("nan"))

            f" | AWQ {res[f'awq_ppl_{d}']:.4f}")

        log(f"[eval] {'PASS' if v else 'FAIL'}  {k}")

#!/usr/bin/env python
"""
06_tune.py — stage-wise tuning of the quantization knobs ("hyperparameters").

Rules (strict):
  * the tuning metric is perplexity on eval.tune_dataset (default: WikiText-2 VALIDATION split),
    which is never used by 05_eval.py — the final test numbers are not tuned on;
  * one knob at a time (configs/tune_space.yaml), the winner is carried into the next stage;
  * a change must improve the metric by >= min_improvement (default 0.5%) to be accepted;
  * stops at budget_trials or --budget-hours.

Outputs: <work_dir>/tuning/leaderboard.csv and configs/run.best.yaml (use it for the final run).

    python scripts/06_tune.py --config configs/run.yaml --space configs/tune_space.yaml --budget-hours 3
"""
import csv
import gc
import shutil
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
import yaml  # noqa: E402

from awq.calib import get_eval_tokens  # noqa: E402
from awq.cli import parser  # noqa: E402
from awq.config import load_config  # noqa: E402
from awq.evaluate import perplexity  # noqa: E402
from awq.model_io import load_quantized  # noqa: E402
from awq.pipeline import quantize_model  # noqa: E402
from awq.utils import Logger  # noqa: E402


def get_value(rc, dotted):
    node = rc
    for p in dotted.split("."):
        node = getattr(node, p)
    return node


def main():
    p = parser(__doc__)
    p.add_argument("--space", default="configs/tune_space.yaml")
    p.add_argument("--budget-hours", type=float, default=None)
    p.add_argument("--keep-trials", action="store_true", help="keep every trial's quantized weights")
    p.add_argument("--out-config", default="configs/run.best.yaml")
    args = p.parse_args()
    base_rc = load_config(args.config, overrides=args.set)
    space = yaml.safe_load(Path(args.space).read_text())
    budget = space.get("budget_trials", 8)
    min_imp = space.get("min_improvement", 0.005)
    tdir = base_rc.work_dir / "tuning"
    tdir.mkdir(parents=True, exist_ok=True)
    log = Logger(tdir / "tune.log")
    from transformers import AutoTokenizer

    from awq.model_io import resolve_model_path
    path = resolve_model_path(base_rc.model, base_rc.revision, base_rc.trust_remote_code)
    tok = AutoTokenizer.from_pretrained(str(path), trust_remote_code=base_rc.trust_remote_code)
    tune_tokens = get_eval_tokens(tok, base_rc.eval.tune_dataset, base_rc.eval.ppl_seq_len,
                                  base_rc.eval.tune_max_windows)
    log(f"[tune] metric: ppl on {base_rc.eval.tune_dataset} ({tune_tokens.shape[0]} windows) — NOT the test set")
    t_start, rows, cache = time.time(), [], {}
    best_over: dict = {}

    def trial(over: dict):
        key = tuple(sorted((k, str(v)) for k, v in over.items()))
        if key in cache:
            return cache[key]
        k = len(rows)
        wd = tdir / f"trial_{k:02d}"
        rc = load_config(args.config, overrides=list(args.set) + [f"{kk}={vv}" for kk, vv in over.items()]
                         + [f"io.work_dir={wd}"])
        t = time.time()
        quantize_model(rc, log=Logger(wd / "quantize.log"))
        model = load_quantized(wd / "quantized", rc.device)
        ppl = perplexity(model, tune_tokens)
        del model
        gc.collect()
        row = {"trial": k, **{kk: str(vv) for kk, vv in over.items()}, "tune_ppl": round(ppl, 5),
               "minutes": round((time.time() - t) / 60, 2)}
        rows.append(row)
        cache[key] = ppl
        log(f"[tune] trial {k}: {over or '(base config)'} -> ppl {ppl:.5f}  ({row['minutes']} min)")
        if not args.keep_trials:
            shutil.rmtree(wd / "quantized", ignore_errors=True)
            shutil.rmtree(wd / "state", ignore_errors=True)
        return ppl

    best = trial({})
    stalls = 0
    for stage in space["stages"]:
        cur = best_over.get(stage["key"], get_value(base_rc, stage["key"]))
        log(f"[tune] stage '{stage['name']}': {stage['key']} in {stage['values']} (current {cur})")
        stage_best, stage_val = best, cur
        for v in stage["values"]:
            if str(v) == str(cur):
                continue
            if len(rows) >= budget or (args.budget_hours and (time.time() - t_start) / 3600 > args.budget_hours):
                log("[tune] budget reached")
                break
            ppl = trial({**best_over, stage["key"]: v})
            if ppl < stage_best * (1 - min_imp):
                stage_best, stage_val = ppl, v
        if stage_val != cur:
            best_over[stage["key"]] = stage_val
            log(f"[tune] stage winner: {stage['key']}={stage_val}  ppl {best:.5f} -> {stage_best:.5f}")
            best, stalls = stage_best, 0
        else:
            stalls += 1
            log(f"[tune] stage kept {stage['key']}={cur}")
        if stalls >= space.get("patience_stages", 3) or len(rows) >= budget:
            break

    fields = sorted({k for r in rows for k in r}, key=lambda x: (x not in ("trial",), x))
    with open(tdir / "leaderboard.csv", "w", newline="") as fh:
        w = csv.DictWriter(fh, fieldnames=fields)
        w.writeheader()
        w.writerows(sorted(rows, key=lambda r: r["tune_ppl"]))
    final = load_config(args.config, overrides=list(args.set) + [f"{kk}={vv}" for kk, vv in best_over.items()])
    final.save(args.out_config)
    log(f"[tune] best overrides {best_over} -> {args.out_config}  (tune ppl {best:.5f})")
    log(f"[tune] leaderboard -> {tdir / 'leaderboard.csv'}")
    log("[tune] NEXT: run 03_quantize.py + 05_eval.py with the best config for the final, untuned-on test numbers.")



if __name__ == "__main__":
    main()

#!/usr/bin/env python
"""
07_export.py — package the result.

  native  : our format (any architecture; load with awq.load_quantized)       -> <work_dir>/export/native
  autoawq : standard AWQ GEMM format for vLLM / SGLang (needs folded scales)  -> <work_dir>/export/autoawq

    python scripts/07_export.py --config configs/run.yaml --format native,autoawq
"""
import shutil
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
from safetensors import safe_open  # noqa: E402

from awq.cli import parser, run_config  # noqa: E402
from awq.export import export_autoawq, gemm_dequant  # noqa: E402
from awq.quantizer import dequantize, unpack_int4  # noqa: E402
from awq.utils import Logger, read_json  # noqa: E402


def check_autoawq(qdir: Path, out: Path, log, n: int = 4) -> float:
    """Decode a few layers from both formats; they must give identical weights."""
    qc = read_json(qdir / "quant_config.json")
    names = list(qc["linears"])[:n]
    worst = 0.0
    nat, gem = {}, {}
    for f in qdir.glob("*.safetensors"):
        with safe_open(str(f), framework="pt") as h:
            for k in h.keys():
                nat[k] = f
    for f in out.glob("*.safetensors"):
        with safe_open(str(f), framework="pt") as h:
            for k in h.keys():
                gem[k] = f
    for name in names:
        with safe_open(str(nat[name + ".qweight"]), framework="pt") as h:
            w_nat = dequantize(unpack_int4(h.get_tensor(name + ".qweight")), h.get_tensor(name + ".scales").float(),
                               h.get_tensor(name + ".qzeros"), qc["group_size"], dtype=__import__("torch").float32)
        with safe_open(str(gem[name + ".qweight"]), framework="pt") as h:
            w_gem = gemm_dequant(h.get_tensor(name + ".qweight"), h.get_tensor(name + ".qzeros"),
                                 h.get_tensor(name + ".scales"), qc["group_size"])
        d = (w_nat - w_gem).abs().max().item() / (w_nat.abs().max().item() + 1e-12)
        worst = max(worst, d)
        log(f"[export] check {name}: max rel diff native vs GEMM = {d:.2e}")
    return worst


def main():
    p = parser(__doc__)
    p.add_argument("--format", default="native,autoawq")
    args = p.parse_args()
    rc = run_config(args)
    log = Logger(rc.work_dir / "export.log")
    qdir = rc.work_dir / "quantized"
    fmts = [f.strip() for f in args.format.split(",") if f.strip()]
    ok = True
    if "native" in fmts:
        dst = rc.work_dir / "export" / "native"
        shutil.copytree(qdir, dst, dirs_exist_ok=True)
        log(f"[export] native -> {dst}")
    if "autoawq" in fmts:
        dst = rc.work_dir / "export" / "autoawq"
        try:
            export_autoawq(qdir, dst, log=log)
            worst = check_autoawq(qdir, dst, log)
            ok &= worst < 1e-2           # fp16 rounding of scales only
            log(f"[export] GEMM layout check {'PASS' if worst < 1e-2 else 'FAIL'} (worst rel diff {worst:.2e})")
        except RuntimeError as e:
            log(f"[export] autoawq NOT produced: {e}")
            ok = False
    sys.exit(0 if ok else 1)


if __name__ == "__main__":
    main()

def _llama_block():
    from transformers import LlamaConfig
    from transformers.models.llama.modeling_llama import LlamaDecoderLayer, LlamaRotaryEmbedding

    cfg = LlamaConfig(hidden_size=64, intermediate_size=128, num_attention_heads=4, num_key_value_heads=4,
                      num_hidden_layers=1, vocab_size=100)
    torch.manual_seed(0)

    pos = torch.arange(x.shape[1]).unsqueeze(0)
    cos, sin = rope(x.float(), pos)
    out = blk(x, position_embeddings=(cos.double(), sin.double()), position_ids=pos)
    return out[0] if isinstance(out, tuple) else out

"""Example plugin: a tiny custom (non-transformers) language model. Used by tests/test_plugin.py.

Copy this file as a template for your own model: implement load(), blocks(), calib_batches().
"""
import torch
import torch.nn as nn


class Block(nn.Module):
    def __init__(self, d):
        super().__init__()
        self.norm = nn.LayerNorm(d)
        self.up = nn.Linear(d, 4 * d)
        self.down = nn.Linear(4 * d, d)

    def forward(self, h):
        return h + self.down(torch.relu(self.up(self.norm(h))))


class TinyLM(nn.Module):
    def __init__(self, vocab=300, d=64, n=2):
        super().__init__()
        self.emb = nn.Embedding(vocab, d)
        self.layers = nn.ModuleList(Block(d) for _ in range(n))
        self.head = nn.Linear(d, vocab)

    def forward(self, x):
        h = self.emb(x)
        for layer in self.layers:
            h = layer(h)
        return self.head(h)


def load():
    torch.manual_seed(0)
    return TinyLM().eval(), None


def blocks(model):
    return model.layers
